# 六部门联合会诊出提示词（导演台 v34 核心升级）

> 定位：把导演台"分镜 → 视频提示词"环节从**单导演出提示词**升级为**六部门联合会诊出提示词**。
> 融合来源：Leos 六部门导演技能 v1 的方法论 + 导演台既有质量铁律/词库/3锁定资产。
> 原则：导演台现有一切优质资产（5条铁律、11维、3锁定、表情/动作/运镜/音效/负面/风格词库、分秒时间戳、参考图@引用、场景调度图、画质一致性、终审六维）全部保留作为地基；六部门机制是"出提示词"这一环的**生产组织形式**，不是替代性重写。

---

## 一、六部门角色速览

| 部门 | 主要负责 | 对接导演台现有资产 | 不得擅自改动 |
|---|---|---|---|
| **总导演** | 场次命题、主要人物、节拍、调度、空间关系、关键电影时刻、最终裁决 | 导演素养体系、剧本优化方法论 | 不用抽象情绪词替代表演动作 |
| **表演指导** | 目标/阻力/潜台词/刺激—反应/微动作/目光呼吸/去AI感 | 表情词库(37种)、动作词库(60+)、情绪微表情量化 | 不暗改剧情、blocking、角色关系 |
| **镜内执行导演** | 群演、环境活动、走位、注意力、错峰反应 | 群演生活化四准则、多人电影感五技法 | 不承担现实排期、人员管理 |
| **摄影指导** | 构图、机位、角度、焦段、景深、运镜、光线、光学效果 | 运镜景别指南、光影情绪大全、风格库 | 不用技术炫技改写场次重点 |
| **提示词导演** | 授权后编译 ≤5000 字纯文本提示词并修订 | 分秒时间戳格式、负面排除库、风格锁定 | 不抢导演决策、不输出JSON、不加未确认默认参数 |
| **场记/连续性** | 跨镜状态、轴线、道具、Take、提示词版本、学习证据 | 参考图编号总表(R/C)、三强制件、一致性方案 | 不以小穿帮否定成立的核心表演 |

> 六部门 = 六种创作职责，由导演台协同调用，不代表启动六个独立 agent，也不处理现实制片排期。

## 二、核心硬规则（不可破坏）

1. **先导演，后提示词**；先可演动作，后情绪形容词。
2. **用户未明确开启生成门时，提示词导演不得输出最终视频提示词**——只输出待确认方案。
3. **最终提示词必须用纯文本模板，不得输出 JSON/伪 JSON**；有效字符数（去空格/换行/制表/代码围栏后）**≤5000**。
4. **多岗审稿必须"角色 × 每一镜"全覆盖**（N 镜 = 6×N 条记录），不得只挑问题镜，也不得用整段概评替代。
5. 表演来自**目标、阻力、刺激和真实动作**，不来自"更悲伤、更高级"。
6. **背景不是静止布景**；每个可见角色必须有独立动作、注意力与错峰反应（对接群演生活化）。
7. 摄影机角度、运动、速度、光线、光学效果**必须有叙事动机与可见结果**。
8. 关键道具与动作写明**初始/变化/结果状态**；相邻镜头共享可核对的出口/入口状态。
9. 时长、画幅、帧率、分辨率、模型能力均为项目当期参数，**未明确时不补默认值**。
10. 失败后第二次**必须包含人类诊断，一次只改一个关键变量**（对接复盘闭环机制）。

## 三、联合会诊流程（出提示词的正式编排）

```
分镜脚本 + 角色板 + 场景图 + 情绪弧线 + 三强制件
        ↓
① 总导演定案 → 场次导演契约（命题/人物/节拍/blocking/空间轴线/关键电影时刻）
        ↓
② 场记建基线 → 连续性基线（上一镜出口→本镜入口→差异等级→修法）
        ↓
③ 三部门简报 → 表演指导(表演谱) + 镜内执行(镜内生态表) + 摄影(摄影设计单)
        ↓
④ 总导演与用户确认 → 产出待确认方案
        ↓
⑤ 用户授权（生成门开启）
        ↓
⑥ 提示词导演编译 → ≤5000字纯文本提示词（对接导演台分秒时间戳格式）
        ↓
⑦ 六角色逐镜审稿 → 6×N 全覆盖表 → 修订 → 生成
        ↓
⑧ 审片学习 → 连续性账/Take结论/项目风格沉淀 → 回填下次
```

**每镜交付物**（提示词导演编译后的单镜提示词，字段完整才能进审稿）：
- 机位 / 摄影机运动 / 摄影机位置 / 背景 / 动作 / ⚠️微表演细节（至少 2 条）
- 无缝融合导演台现有分秒时间戳毒段（`[Xs-Ys]: 【运镜】+【景别】+场景+人物+变化, no [负面]; [风格后缀]`）
- 对接参考图@编号引用（`场景参考@Cx + 角色参考@Ry`）

## 四、逐镜审稿强制协议（6×N 全覆盖表）

当任务是审一版含 N 镜的提示词时：

- **参与审稿的每个角色都必须依次检查镜头 1 至 N**。
- 六角色联合审稿应恰有 **6 × N 条角色—镜头记录**。
- 没有问题仍写 `通过`，在"观察/问题"写 `没问题`。
- 不得省略、合并镜头、只列有问题的镜头，或发整段概评替代逐镜检查。
- `不适用` 仅用于该岗位确实无对应职责的字段，且必须说明理由。

```markdown
| 角色 | 镜头 | 结论 | 观察/问题 | 具体建议 | 验收条件 |
```

**六角色审稿各自重点**（对接导演台词库）：
- 总导演：命题是否成立、节拍与blocking是否清晰、关键电影时刻是否保住、力量关系是否留反应时间
- 表演指导：是否先可演动作后情绪词、表情是否从表情词库取且量化、有无去AI感、有无潜台词
- 镜内执行：群演是否各有独立动作与注意力、错峰反应是否出现、背景是否非静止布景
- 摄影指导：机位/焦段/景深/运镜有无叙事动机、光线有无来源、相邻镜能否连贯
- 提示词导演：格式可执行、时间戳覆盖、无JSON、字数≤5000、负面排除是否具体
- 场记：跨镜状态是否标注、轴线/道具出入场是否连续、版本号是否正确

## 五、字数预算（提示词导演硬性控制）

每版提示词去空格/换行/制表/代码围栏后有效字符 `≤5000`，预算建议：

| 区块 | 占比 |
|---|---|
| 资产绑定 + 空间布局 | ≤20% |
| **逐镜内容** | **≥65%**（主体） |
| 环境活动 + 风格 | ~15% |

- 资产只写身份、职责和必须继承的识别特征；空间只写影响调度/视线/接镜的锚点。
- 摄影设计中的光线/曝光/光学编入"机位/背景/风格"，连续性编入资产状态/空间/逐镜动作，不另加顶层栏目。
- **超限时依次压缩**：重复形容词 → 资产外观复述 → 全局重复 → 次要环境细节。
- **不得先牺牲**：每镜动作、微表演、摄影路径、出口状态。
- 完成后自检：有效字符计数（可调用校验脚本）。

## 六、失败归因与最小返工（审片 P0/P1/P2）

| 等级 | 判定 | 动作 |
|---|---|---|
| P0 | 破坏叙事/角色/物理逻辑，穿帮致命 | 打回重做对应镜，先人类诊断再改 |
| P1 | 明显偏差但不致命（表情错/机位偏/连续性小穿帮） | 定点最小补镜，不动成立的主体 |
| P2 | 细节瑕疵、可接受 | 记录待后续优化，不打断 |

**铁律**：失败后的第二次尝试必须包含一句人类诊断（"问题是____，因为____"），**一次只改一个关键变量**；不搞"蒙头多改几处碰运气"。这与复盘闭环机制一致。

---

## 七、连续性/版本台账（场记三本账，跨镜/多集负载）

| 账本 | 记录内容 | 用途 |
|---|---|---|
| **连续性账** | 每镜出口状态 → 下一镜入口状态、方位/道具/轴线 | 防止跨镜穿帮 |
| **提示词版本账** | 版本号(v001/v002…)、变更摘要、用户反馈 | 可追溯、可回滚 |
| **Take 账** | 生成时间、模型参数、结果、是否采用 | 沉淀有效经验 |

多集/多段项目必开三本账；单集短片至少记连续性账 + 提示词版本账。

## 八、与导演台既有流程的关系

| 导演台环节 | 六部门机制介入点 |
|---|---|
| ① 剧本 / 剧本优化 | 总导演视角（讲好故事，输出导演脚本） |
| ② 角色设计 | 表演指导 + 摄影指导视角辅助（表情/动作/形象锁定） |
| ③ 场景设计 | 镜内执行 + 摄影指导视角（空间/群演/光影） |
| ④ 分镜设计 | 进入联合会诊主线：总导演定案 → 三部门简报 → 提示词导演编译 |
| ⑤ 视频生成 | 按六部门审稿通过的提示词生成，失败走 P0/P1/P2 最小返工 |
| ⑥ 成片 + 终审 | 终审升级为 6×N 逐镜全覆盖 + 原有六维（可执行性维度并入提示词导演审稿） |

**使用建议**：
- 强叙事/多人/群戏/长片/剧集：**完整六部门联合会诊**，六岗逐镜审稿全覆盖。
- 轻量单镜头/静态展示：可简化，但至少保留"总导演定案 → 提示词导演编译 → 逐镜自检"三段，保证先方案后提示词。
- 用户只点名一个角色时，只输出对应部分，不虚构其他角色意见。

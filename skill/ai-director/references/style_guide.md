## 九、视频专用风格后缀模板

### 通用电影感
```
cinematic lighting, film grain, shallow depth of field, 2.39:1 aspect ratio, color graded, professional cinematography, anamorphic lens flare
```

### 国风写实
```
Chinese ink painting aesthetic, silk texture, traditional color palette, subtle ink wash background, guohua style, museum quality detail
```

### 暗黑奇幻
```
dark fantasy atmosphere, volumetric fog, rim lighting, gothic architecture, muted color palette, dramatic shadows, oil painting texture
```

### 赛博朋克
```
neon-lit cyberpunk city, rain-soaked streets, holographic advertisements, chromatic aberration, high contrast, teal and orange grading
```

### 治愈绘本
```
warm watercolor illustration, soft pastel colors, gentle brush strokes, dreamy atmosphere, children's book style, cozy and heartwarming
```

### 复古胶片
```
vintage film photography, Kodak Portra 400, natural grain, warm color cast, slight vignette, nostalgic mood, 35mm film
```

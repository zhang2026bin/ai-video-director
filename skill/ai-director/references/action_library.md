# 肢体动作提示词词库

来源整理：个人知识库 + 火星时代AIGC动作提示词合集 + AI打斗动作教程 + AI预备动作理论
整合时间：2026-07-07

## 核心原则

**万能公式**：主体 + 身体姿态 + 肢体动作细节 + 表情状态 + 场景氛围 + 画质风格

**三条铁律**：
1. 不写"做什么"，写"怎么做"：不是"走路"，而是"脚跟先着地再过渡到脚尖，手臂与腿自然反节奏摆动"
2. 一个部位动，其他部位也跟着微动：转头→头发延迟飘+肩膀微转+视线先变
3. 动作叠情绪：不是"笑"，而是"累了一天终于笑出来"

## 一、预备动作体系（让动作从"机器人"变"活人"）

真实动作永远有预备。没有预备的动作=提线木偶。

### 1. 视线预备
适用：转头、看物体、对视
写法：转头之前先让眼睛往那个方向移动，头部微微偏转一个小角度
示例："角色先垂眼，然后缓缓抬起视线看向前方，头部跟随转动"

### 2. 重心预备
适用：站起、坐下、迈步、伸手
写法：主要动作前，先让重心向动作方向轻微移动
示例："要伸手拿桌上的杯子→肩膀微微前倾，上半身向桌子方向倾斜一个小角度"
示例："要从椅子上站起来→双手撑住椅子扶手，身体前倾"

### 3. 反向预备
适用：需要力量感/速度感的动作（挥手、投掷、拍桌）
写法：先向反方向移动一小段，再向目标方向加速
示例："挥手打招呼→手臂先向后微微摆动，然后向前上方挥出"

### 预备动作幅度参考
- 日常动作（拿水、转头）：幅度小，0.3-0.5秒
- 情绪化动作（激动挥手、拍桌）：幅度中等，0.5-1秒
- 夸张动作（动画风格）：可大到1-2秒

## 二、站姿（6种）

### ① 自信站姿
双脚与肩同宽站立，双手自然垂放身体两侧，重心均匀分布，肩部后展，下巴微抬，表情自信但不紧绷
关键点：双脚与肩同宽+肩部后展=自信感，不是僵硬挺直

### ② 放松站姿
重心放在一条腿上站立，一只手随意插兜，另一只手松松拿着手机，脊柱有轻微弧度而非笔直
关键点：重心偏移+脊柱自然弧度=放松

### ③ 倚靠站姿
靠在水泥墙上，双臂松松交叉在胸前，一只脚平踩墙面，头微低，视线看向侧方而非镜头
关键点：靠墙+视线不直视镜头=故事感

### ④ 双手叉腰站姿
双手叉腰站立，手肘微向外弯，重心均匀落在双脚，头微歪，脸上带着似笑非笑的表情

### ⑤ 疲惫站立
肩膀耷拉，背微驼，重心偏向一条腿，一只手揉着后颈或太阳穴，头略歪向一边好像累得撑不住

### ⑥ 紧张站立
双手在身前交握，指节因紧张微微泛白，双脚并拢，身体僵硬挺直，肩膀微微耸起

## 三、坐姿（5种）

### ① 办公坐姿
坐在桌前，身体微前倾，手肘搁在桌上，一只手放在键盘上正在打字——手指悬在键帽上方，食指刚好按下，另一只手在触控板上滑动
关键点：打字拆到手指级别

### ② 放松坐姿
坐在沙发上双腿交叠，上半身靠进靠垫里，一条手臂搭在扶手上，另一只手松松握着杯子搁在大腿上，头微后仰，眼睛半闭
关键点：半闭眼+搭着而非僵着

### ③ 专注坐姿
盘腿坐在地上，背部微弯，一本书搁在腿上，一只手压着书页，另一只食指正顺着某行字划过，头低垂，头发微向前落
关键点：手指顺着文字划过

### ④ 紧张坐姿
坐在椅子边缘，背挺直，双手在膝上交握，手指交叉指节因紧张微微泛白，双脚平踩地面，膝盖并拢，身体微向前倾
关键点：椅子边缘+指节泛白=紧张

### ⑤ 崩溃坐姿
双手抱头，身体前倾蜷缩，手肘撑在膝盖上，手指插进头发里，肩膀剧烈起伏（哭泣/绝望）

## 四、行走（6种）

### ① 自信走步
朝前走来，步伐稳健——脚跟先着地再过渡到脚尖，手臂与腿以自然反节奏摆动，下巴微抬，微风掀起衣角
关键点：脚跟先着地再过渡到脚尖（生物力学描述）

### ② 悠闲漫步
步伐缓慢，步幅偏短，双手插在大衣口袋中，肩膀放松，头部偶尔转向环顾四周
关键点：慢走不写"slow"，写"短步幅+不匆忙"

### ③ 匆忙赶路
大步快速行走，步伐急切，一只手抓着包带，另一只手在行走中看表，微微喘息，嘴微张，头发因运动而凌乱
关键点：边走边看表=焦虑赶路的标志性动作

### ④ 回眸
朝前走去，忽然停顿，头转过来越过肩膀回望，头发随转头有轻微延迟飘动，身体仍面向前方只有上半身微转
关键点：头发延迟飘动=头发永远比头慢半拍

### ⑤ 疲惫行走
步履缓慢略带拖沓，步幅短，肩膀下垂，手臂摆动幅度小，每一步脚掌几乎不离开地面，身体微微前倾，头低垂
关键词：步履缓慢、略带疲态、拖沓步伐

### ⑥ 惊恐奔跑
身体前倾30度，双臂大幅摆动不协调，脚步沉重踩出泥水飞溅，头部不断左右转动回望，呼吸急促嘴巴大张，跑姿狼狈重心不稳
关键词：重心不稳、脚步沉重、狼狈、不断回望

## 五、手部动作（8种）

### ① 拿杯子
一只手环握杯子，手指自然弯曲扣住杯柄，拇指搭在杯柄上缘，另一只手托住杯底，杯子缓缓举向微张的嘴唇
必加约束：five fingers per hand, anatomically correct

### ② 看手机
双手拿着手机，拇指悬在屏幕上方正在滑动，头低下约30度，手机屏幕向面部投射柔和的蓝白色光
关键点：屏幕光照脸=氛围感关键

### ③ 打字
双手悬停在键盘上方，食指正按压一个键帽而其余手指保持微抬状态，每次敲击时手腕有细微联动

### ④ 翻书
一只手托着翻开的书，另一只手伸过去翻页——指尖触及页面上角，书页悬在半空中处于翻动动作之间
关键点：书页在半空中的翻动瞬间

### ⑤ 握拳
手指逐根卷曲扣紧掌心，拇指压在最外侧两指上，指节泛白，前臂肌肉紧绷，青筋浮现

### ⑥ 颤抖的手
手指每秒2-3次频率小幅度颤抖，手指微曲不完全伸直，指尖间距不均匀

### ⑦ 撑地
五指张开撑在地面上，手臂伸直但手肘微弯缓冲，手指因承重微微发白，手掌与地面接触面积最大

### ⑧ 松开/放手
手指从紧握状态逐根展开，先松开小指→无名指→中指→食指→拇指，整个过程用时1.5秒

## 六、战斗/对抗动作（8种）

### ① 挥拳
反向预备：肩膀先向后转→腰部带动上半身扭转→全身力量从脚底经腰传到拳头→拳头沿直线冲出→命中瞬间拳头握紧到极限，指节泛白

### ② 挥刀/劈砍
双手握刀举过头顶→身体重心前移→手臂沿弧线下劈→刀刃切入目标→身体随惯性前倾→后脚蹬地稳住重心

### ③ 格挡
双臂交叉护在身前→小臂外侧承受冲击力→身体因巨力向后踉跄→双脚在地面擦出两道沟痕→借力稳住重心

### ④ 闪避
视线预判来物方向→上半身向侧方倾斜→重心瞬间转移到前脚→后腿蹬地发力→整个身体侧移30厘米→衣角因惯性继续原方向飘动

### ⑤ 被击飞
身体因撞击向后仰→双脚离地→手臂失控甩出→背部重重砸在地面→扬起尘土→身体弹起一次后瘫倒

### ⑥ 落地蓄力
从高空坠落→双脚重重砸在地面发出沉闷声响→地面被踩出浅坑→膝盖微屈缓冲→身体因惯性前倾→肩膀下沉→胸口因剧烈呼吸快速起伏→额头汗珠滴落→手臂肌肉紧绷轻微颤抖→双脚缓慢蹬地重心逐渐压低

### ⑦ 对峙
双脚分开与肩同宽微屈膝→重心压低→一手握武器垂在身侧→另一手横在胸前→下巴微收→眼神锁定对手→呼吸平稳但鼻翼微张→全身肌肉处于随时爆发的紧绷状态

### ⑧ 受伤踉跄
身体被冲击力推退→连退三步→第三步脚后跟绊到地面→身体前倾快要摔倒→一手下意识伸出撑地→另一手捂住受伤部位→手指缝渗出血液

## 七、逃跑/求救动作（6种）

### ① 摔倒后爬起
脚下一滑身体前倾→双手下意识前伸→膝盖先着地→手掌撑地→膝盖在泥地上划出两道痕→咬牙用双臂撑起上半身→一条腿先收回脚下→另一条腿跟上→踉跄站起继续跑

### ② 被人拉扯
一只手被后方的人抓住手腕→身体因拉力向后仰→另一只手向后伸出想抓住什么→回头看向追来的人→表情从惊恐变为绝望→手被松开后手臂无力垂下

### ③ 一瘸一拐奔跑
一条腿明显使不上力→每跑一步身体向健侧倾斜→伤腿落地时膝盖弯曲角度不够→脚掌拖地发出刮擦声→双手不协调摆动→速度明显比正常奔跑慢一半

### ④ 互相搀扶
一个人把另一个人的手臂搭在自己肩上→一手搂住对方腰→另一手搀扶对方手臂→两人步速不一致→搀扶者不断调整步伐配合→被搀扶者每走一步身体都在晃动

### ⑤ 绝望呼喊
双手拢在嘴边做成喇叭状→头向后仰→嘴巴张到最大→声音从喉咙深处发出→喊完后双手垂下→肩膀因喘息剧烈起伏→头缓缓低下

### ⑥ 放弃挣扎
身体从紧绷状态突然松弛→手臂从举起状态无力垂下→手指张开不再握拳→膝盖弯曲身体下沉→最终跪倒在地→头低垂→双手搭在身体两侧→全身不再有任何动作

## 八、情绪肢体语言（10种）

### ① 愤怒
牙关紧咬→太阳穴青筋微凸→拳头攥紧指节发白→肩膀绷紧→身体微微前倾呈进攻姿态→鼻翼扩张→呼吸急促

### ② 恐惧
身体蜷缩→双臂环抱胸前→肩膀耸起护住脖子→眼睛瞪大瞳孔收缩→不断左右扫视→脚步后退→呼吸急促浅短

### ③ 悲伤
肩膀耷拉→头低垂→双臂无力垂在身侧→步伐沉重→偶尔抬手擦眼角→嘴角下拉→全身动作幅度缩小到最小

### ④ 坚定
下巴微抬→肩膀后展→双脚站稳与肩同宽→双手握拳垂在身侧但不过度紧绷→眼神直视前方不移开→呼吸平稳深长

### ⑤ 犹豫
一只手伸出一半又缩回→重心在两只脚之间来回切换→视线在两个方向之间反复移动→嘴唇抿紧又张开→手指无意识地搓动

### ⑥ 放松
肩膀自然下沉→手臂松松垂在身侧→手指微微弯曲不握拳→重心放在一条腿上→呼吸缓慢深长→头部偶尔无意识转动

### ⑦ 警惕
身体微微侧转减小暴露面积→一只手搭在武器上→脚步放轻脚跟先着地→头部缓慢扫视四周→瞳孔收缩→呼吸变浅变轻

### ⑧ 忠诚/守护
身体微微侧向被守护者→一只手搭在对方肩上或挡在身前→目光扫视四周保持警戒→下巴微收→肩膀宽阔呈保护姿态

### ⑨ 绝望
双手抱头→身体蜷缩→肩膀剧烈起伏（哭泣）→或：身体僵直不动→双手无力垂下→眼神空洞失焦→全身肌肉失去张力

### ⑩ 如释重负
紧绷的身体突然松弛→肩膀下沉→头微后仰→双眼闭合→深呼一口气→嘴唇微张→手指从紧握状态逐根展开

## 九、动作描写万能模板

### 基础模板
```
[预备动作0.3-0.5秒]→[主动作]→[身体联动反馈]→[环境交互]
```

### 完整模板
```
[视线/重心预备]→[发力起点]→[动作路径]→[终点状态]→[用时]→[生理反应]→[环境反馈]
```

### 实战示例
```
错误：他站起来跑了
正确：他的视线先看向门口（视线预备）→双手撑住膝盖（重心预备）→右脚先蹬地发力（发力起点）→身体从坐姿弹起前倾（动作路径）→三步冲到门口（终点+用时）→胸口剧烈起伏额头冒汗（生理反应）→门被推开撞到墙上发出巨响（环境反馈）
```

### 打斗动作模板
```
[对抗局势]→[角色发力逻辑]→[动作结果]→[身体反馈]→[环境破坏]
```

### 实战示例
```
错误：主角打了一拳
正确：主角被压制在墙上勉强格挡（对抗局势）→在敌人出拳间隙双腿猛蹬墙面借力（发力逻辑）→身体腾空全身力量汇聚于右拳砸向对方面门（动作结果）→拳头命中时手臂因冲击力微微发颤（身体反馈）→对方牙齿飞溅身体后仰气浪掀起头发和衣角（环境破坏）
```

## 十、动作强度词速查

| 强度 | 关键词 | 适用场景 |
|------|--------|---------|
| 极轻 | 微微、轻轻、几乎不可见 | 暗示、犹豫、试探 |
| 轻 | 缓慢、柔和、从容 | 放松、日常、温柔 |
| 中 | 稳健、有力、果断 | 正常行动、工作状态 |
| 强 | 迅速、猛烈、用力 | 紧急、战斗、逃跑 |
| 极强 | 猛然、狠狠、拼尽全力 | 爆发、崩溃、最后一击 |

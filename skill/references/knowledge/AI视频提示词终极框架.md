## 第一部分：写法铁律（贯穿全流程，任何提示词都必须遵守）

### 铁律1：教小孩画画

假设读提示词的AI是一个会画画但完全不懂故事的小孩。你说的每一句话，它都按字面意思画。所以：

- **每个细节都必须说清楚**，不留模糊空间
- **不要写"缓缓/慢慢/微微"**——写"用2秒从A移到B"
- **不要写"高级/好看/震撼"**——写具体的材质、光线、色彩、空间、镜头
- **不要写"电影感"**——写"24mm f5.6 深景深 胶片颗粒感 IMAX画幅"
- **表情要五官逐一写+量化**：不是"开心"，而是"嘴角上扬15度，眼角挤出2道鱼尾纹，眉毛舒展至水平"
- **动作要写发力起点→路径→终点→用时**：不是"转身"，而是"右脚蹬地发力→腰部带动上半身左转90度→左脚落地站稳→用时1.2秒"

### 铁律2：指令式 > 描述式

| 维度 | 描述式（差） | 指令式（好） |
|------|------------|------------|
| 语气 | "画面中角色微笑着转身" | "必须遵循面板顺序，不得重新诠释动作、姿势、镜头角度" |
| 素材引用 | "参考上图" | "角色参考@图片1，场景参考@图片3，故事板参考@图片4" |
| 约束 | "no xxx" | "不得重新诠释""不能是冗长拖沓"——正面指令隐含禁止 |
| 节奏 | "节奏感强" | "每个节拍=动作快照，不是冗长动作，最终节拍前不松懈不停顿" |

### 铁律3：反面约束 + 正面指令配对

在描述关键动作时，直接嵌入"不要X，而是Y"，而不是把所有禁止项堆到最后：

**❌ 错误写法**：
```
积木拆解展开。不要瞬间炸开，不要乱飞。
（最后才说禁止，AI可能已经按"炸开"画了）
```

**✅ 正确写法**：
```
积木按照真实结构逻辑逐步拆解展开——不要瞬间炸开，也不要杂乱乱飞，而是有节奏地分层分步展开。先拆外部大件，再逐步露出并分离内部结构。
```

**配对公式**：`[正确行为描述] ——不要[常见错误1]，也不要[常见错误2]，而是[精确要求]。先[步骤1]，再[步骤2]。`

### 铁律4：叙事思维（写提示词 = 写小说片段）

读者（AI）能从文字里"看见"画面，而不只是"知道"有什么东西。

**场景构图三层法**：
- 前景：质感细节（"散落的彩色积木块，一块正从桌面滑落"）
- 中景：主体动作（"黎侯虎坐在积木旁，身体前倾，双手叉腰"）
- 远景：氛围定调（"温暖的游戏角，矮书架、毛绒抱枕、落地窗"）

**五感法**：
- 视觉：光影方向、色温、空气透明度
- 听觉暗示：画面中能"听到"的元素（铃铛声、水声、风声），用文字暗示声音存在
- 触觉暗示：温度和质感（"赤脚踩在滚烫沙地"）
- 嗅觉暗示：场景特有气味（雨后泥土、海盐、松脂）
- 情绪氛围：不直接说"悲伤"，而是用环境传递——"空荡秋千在风中缓缓摆动"

**人物小说笔法**：
- 不写"一个女人站着"→ 写"她微微侧身，风将碎发吹过半阖的眼，嘴角有一丝不确定的弧度"
- 动作要有动机：不是"手举起来"，而是"指尖触碰到门框时犹豫着停住"
- 微表情比大动作更有戏：攥紧的指节、移开的目光、抿住的下唇

### 铁律5：量化禁模糊

| 禁止写法 | 替代写法 |
|---------|---------|
| 缓缓/慢慢/微微 | 用2秒从A移到B / 0.5秒完成转身 |
| 轻轻地 | 指尖以2N力度触碰表面 |
| 大大的/小小的 | 占画面60% / 直径约3公里 |
| 逐渐变化 | 0-3秒眉头紧皱→3-5秒眉头舒展→5-6秒嘴角上扬 |
| 电影感/高级感 | 写具体：24mm f5.6 深景深 胶片颗粒 IMAX画幅 |

## 第二部分：生图提示词框架（11维 + 3锁定）

### 用途
生成高质量单张图片：参考图、角色板、场景图、关键帧。

### 11维场景框架

| # | 维度 | 核心要求 | 写法要点 |
|---|------|---------|---------|
| 1 | 具体场景 | 有画面故事感的具体空间，不是普通背景 | 不写"森林"→写"阳光穿过针叶林缝隙，光斑落在苔藓覆盖的倒木上" |
| 2 | 世界观/美学 | 匹配主题的风格年代 | 现代写实/复古美式/末日废土/赛博朋克/东方玄幻/暗黑童话/3D毛绒绘本 |
| 3 | 主体细节 | 颜色/材质/纹理/状态/反光/破损/湿度/瑕疵/边缘 | 微观可触——AI应该能"摸到"这个物体 |
| 4 | 空间结构 | 前景+中景+背景三层 | 前景给质感，中景放主体，远景定氛围 |
| 5 | 时间天气空气 | 清晨/黄昏/雨后/雾气/烟雾/热浪 | 空气透明度决定画面质感 |
| 6 | 光线设计 | 光源方向+光质+高光暗部处理 | 电影布光思维：主光+辅光+轮廓光 |
| 7 | 色彩影调 | 主色+辅色+饱和度+对比度+冷暖+影调 | 色彩即情绪 |
| 8 | 镜头参数 | 机身+焦段+光圈+景深+对焦+焦外 | 摄影语言精确表达 |
| 9 | 氛围情绪 | 情绪+反差点 | 温暖但孤独/童真但诡异/奢华但破败 |
| 10 | 画质风格 | 电影级/胶片/3D渲染/水彩 | 锁定渲染方式 |
| 11 | 反向约束 | 杜绝CG感/塑料感/过度美化/卡通/错透视 | 质量底线 |

### 3锁定技巧（保证跨图片一致性）

**🔒 锁构图**：主体占画面60%+景深虚化
**🔒 锁风格Token**：固定风格词组合不变形（如"3D cartoon Pixar-style rendering, soft velvety matte finish"全程不变）
**🔒 锁视觉层级**：前景(20%)+中景(60%)+远景(20%)

### 镜头参数速选表

| 画面类型 | 镜头 | 光圈 | 景深 | 典型场景 |
|---------|------|------|------|---------|
| 静物特写 | 50mm/85mm/100mm微距 | f1.8-2.8 | 浅 | 绘本封面、产品展示 |
| 环境场景 | 24mm/35mm | f4-8 | 中-深 | 世界观建立、全景交代 |
| 电影人物 | 35mm/50mm/85mm | f2-4 | 中 | 角色出场、对话场景 |
| 宏大建筑 | 24mm/28mm/35mm | f5.6-8 | 深 | 奇幻/城市全景 |
| 商业广告 | 85mm/100mm微距 | f2.8-5.6 | 浅-中 | 带货图、产品精修 |

### 氛围反差点公式

好的氛围不是单一情绪，而是**主情绪+反向裂隙**：
- 温暖但孤独（家的灯光，窗外无人）
- 奢华但破败（金漆剥落的宫殿）
- 童真但诡异（微笑的布偶在暗角）
- 干净但危险（无菌实验室里的血迹）
- 可爱但紧张（萌物发怒的违和感）

### 角色板提示词写法

不是标准参考表，是**电影般身份板**：
- 不对称布局+大片留白+多样化图像比例
- 英雄全身视角偏离中心作锚点，辅助研究环绕排列
- 身份锁定6要素：相同面部/比例/发型/服装/身体/姿势语言
- 艺术性加分：轮廓剪影区+表情研究区+细节研究区
- 文本极简：名称+角色+核心情绪+视觉标志
- 角色锚定词全程不变，复制粘贴到每一镜

### 生图输出格式

```
【最终场景图片提示词】
一整段中文，不分点，可复制直用。按教小孩画画标准写——每个细节都说清楚。

【镜头参数摘要】
摄影机质感 / 焦段 / 光圈 / 景深 / 对焦位置 / 背景虚化 / 适合原因

【风格锚定词】（如需系列图，此段全程不变）
```

## 第三部分：中间层——分镜故事板

### 用途
文字脚本→黑白线稿分镜+6色箭头标注→视频。**线稿故事板是生视频的视觉权威蓝图**，提示词必须声明"以故事板为权威来源"。

### 6色箭头标注系统

| 颜色 | 功能 | 示例 |
|------|------|------|
| 🔴 红色 | 机位运动/镜头调度 | 🔴箭头标注"镜头缓慢上摇" |
| 🔵 蓝色 | 角色动作轨迹/人群视线 | 🔵箭头标注"人群抬头视线汇聚向飞船" |
| 🟢 绿色 | 互动关系/力量对比 | 🟢标注"飞船与城市的力量对比定格" |
| 🟠 橙色 | 光效/冲击力 | 🟠箭头标注"蓝色脉冲光波从船底向外扩散" |
| 🟣 紫色 | 声音/环境氛围标注 | 🟣标注"全城低频共振" |
| ⚫ 黑色 | 补充标注 | ⚫标注"全城熄灯→黑暗→定格" |

### 故事板提示词模板

```
参考角色@图1，创建一个电影感的[N]格分镜动作故事板，16:9画幅，黑白粗糙铅笔线条绘制规范。

每个面板左上角标有1-N序号，底部带有大写无衬线字体的加粗白色标题。

场景设定：[场景描述]
整体氛围：[氛围词]

面板1 "[英文标题]"：[画面描述]。🔴[镜头标注]。🔵[动作标注]。
面板2 "[英文标题]"：[画面描述]。🟠[光效标注]。🟣[声音标注]。
...（逐格写）

[如需更多标注颜色，继续使用对应颜色]
```

### 分镜层级（玩法分级）

| 层级 | 格数 | 适用场景 | 精度 |
|------|------|---------|------|
| L1 | 6格 | 单一动作 | 简笔画+基本箭头 |
| L2 | 6格 | 简单叙事 | 增加情绪标注 |
| L3 | 12格 | 全维度叙事 | 6色箭头全覆盖 |
| L4 | 12格+ | 冲击力/格斗 | 物理细节+打击感 |

## 第四部分：生视频提示词框架（2声明+6段式）

### 用途
将参考图+故事板转化为AI视频生成器能直接理解执行的完整提示词。

### 前置：2个必写声明（每条视频提示词开头必须写）

**蓝图声明**（锁定画面来源）：
```
使用故事板@图片X作为[N秒]视频的完整视觉和动作来源，从左到右依次遵循所有[N]个镜头；不得重新诠释动作、姿势、镜头角度或能量递进，需保留故事板的镜头顺序、构图多样性和最终定格姿势。
```

**节奏声明**（锁定时间节奏）：
```
将完整的[N]镜头序列压缩到[N]秒，每个节拍必须清晰呈现为动作快照，不能是冗长拖沓的动作；使用紧凑节奏+快速剪辑+流畅转场，最终节拍前不松懈不停顿。
```

### 6段式提示词结构（每段5要素）

#### 段1：运镜开场

| 要素 | 写什么 | ❌错误 | ✅正确 |
|------|--------|--------|--------|
| 1.镜头类型 | 明确景别+角度 | "镜头对着角色" | "50mm中景，平视，与角色眼部等高" |
| 2.运动方式 | 起点→路径→终点→速度 | "镜头移动" | "镜头从角色腰部高度起始，以15度/秒速度上摇至头顶，用时2秒" |
| 3.运动节奏 | 匀速/加速/减速/变速 | "缓慢推进" | "前3秒匀速推进0.5米，最后1秒减速至0.1米/秒停稳" |
| 4.对焦策略 | 对焦哪里+景深变化 | "对焦角色" | "对焦角色右眼，f2.8浅景深，背景柔和虚化" |
| 5.运动理由 | 为什么这么动（叙事目的） | "好看" | "上摇揭示角色头顶的巨大阴影，制造压迫感" |

#### 段2：主体锚定

| 要素 | 写什么 | ❌错误 | ✅正确 |
|------|--------|--------|--------|
| 1.角色外观 | 直接引用角色锚定词，不重写 | "一个可爱小老虎" | 复制角色板锚定词全文 |
| 2.初始姿态 | 身体朝向+重心+四肢位置 | "站着" | "面朝画面右侧，重心在左脚，右脚微抬离地2cm" |
| 3.表情状态 | 五官逐一写+量化变化幅度 | "开心的表情" | "嘴角上扬15度露出小虎牙，眼角挤压出2道笑纹，眉毛舒展水平" |
| 4.服装道具 | 材质+反光+动态+与身体的关系 | "穿着围兜" | "浅绿色三角围兜，棉质哑光，五瓣花刺绣居中，围兜随呼吸微微起伏" |
| 5.物理特征 | 毛发/皮肤/肌肉的物理状态 | "毛茸茸的" | "白色短绒毛，光照侧可见0.5mm绒毛边缘光，腹部随呼吸起伏频率1次/2秒" |

#### 段3：时间线演进

| 要素 | 写什么 | ❌错误 | ✅正确 |
|------|--------|--------|--------|
| 1.逐秒动作 | 每秒发生了什么（3件事：画面状态+谁在做什么+什么在变化） | "然后他生气了" | "0-1秒：积木塔晃动→1-3秒：积木倒塌散落→3-5秒：双手叉腰→5-7秒：跺脚张嘴→7-10秒：脸颊鼓起呼气" |
| 2.动作细节 | 发力起点→路径→终点→用时 | "转身" | "右脚蹬地→腰部带动上半身左转90度→左脚落地→1.2秒完成" |
| 3.变化轨迹 | 关键元素从状态A到状态B的完整过程 | "铃铛动了" | "铃铛从静止→向左摆动15度→回中→向右摆动15度→回中，单次摆动0.8秒" |

#### 段4：环境与氛围

| 要素 | 写什么 | ❌错误 | ✅正确 |
|------|--------|--------|--------|
| 1.空间结构 | 前景质感+中景主体+远景氛围 | "森林场景" | "前景：苔藓覆盖倒木，露珠反光；中景：角色站在倒木旁；远景：针叶林剪影，雾气弥漫" |
| 2.环境动态 | 非主体的环境运动元素 | "有风" | "落叶从画面左上角以30度角飘入，速度0.5m/秒，每隔1.5秒一片" |
| 3.光线变化 | 用7列表格写清楚 | "光线变化" | 见下方光线变化表 |
| 4.色彩变化 | 色相/饱和度/明度随时间的变化 | "颜色变了" | "0-3秒暖黄主调(色相40°/饱和度70%)→7-10秒转为粉橘(色相15°/饱和度80%)" |
| 5.声音暗示 | 画面中能"听到"的元素 | "安静" | "积木碰撞的木质感声响，铃铛金属脆响，远处鸟鸣" |

**光线变化7列表格**（每镜必填）：

| 时间段 | 光源位置 | 光色色温 | 光质 | 照射方向 | 高光位置 | 阴影位置 | 效果 |
|--------|---------|---------|------|---------|---------|---------|------|
| 0-3秒 | 左侧窗户 | 暖黄5500K | 柔和漫射 | 左→右 | 角色左侧脸颊 | 右侧脸颊 | 温暖日常 |
| 3-7秒 | 左侧+铃铛自发光 | 暖黄+金光 | 柔和+点光源 | 双向 | 铃铛周围+面部 | 无明显阴影 | 治愈转折 |

#### 段5：声音提示

| 要素 | 写什么 | ❌错误 | ✅正确 |
|------|--------|--------|--------|
| 1.环境音 | 场景持续存在的背景声 | "安静" | "午后蝉鸣，微风拂过窗帘的沙沙声，远处小孩笑声" |
| 2.动作音 | 角色动作触发的声音 | "有声音" | "积木木块碰撞的清脆嗒嗒声，跺脚的闷响poom" |
| 3.情绪音 | 氛围声音（非写实，情绪层） | "紧张的音乐" | "低频嗡鸣渐强0-7秒，第7秒断裂为一声清脆铃响" |
| 4.音量层级 | 用pp/p/mp/mf/f/ff标注强度 | "很大声" | "环境蝉鸣pp→积木倒塌mf→跺脚f→铃铛脆响ff" |

**音量层级对照**：
- pp (pianissimo)：极弱，几乎听不见
- p (piano)：弱，背景底噪级
- mp (mezzo piano)：中弱
- mf (mezzo forte)：中强，正常对话级
- f (forte)：强，引人注意
- ff (fortissimo)：极强，冲击感

#### 段6：风格约束

| 要素 | 写什么 | ❌错误 | ✅正确 |
|------|--------|--------|--------|
| 1.渲染方式 | 3D/写实/水彩/胶片等具体方式 | "好看的风格" | "3D cartoon Pixar-style rendering, soft velvety matte finish" |
| 2.色彩调性 | 具体色相+饱和度+对比度 | "暖色调" | "马卡龙暖色调，主色暖黄(色相40°)，饱和度70%，柔和对比" |
| 3.镜头质感 | 具体机身+颗粒感+画幅 | "电影感" | "全画幅电影感，轻微胶片颗粒，2.39:1宽画幅" |
| 4.参考锚定 | 风格参考词/参考图 | "像皮克斯" | "Pixar+Ghibli混合，参考@图片1的渲染质感" |
| 5.反向约束 | 杜绝什么 | "不要不好看" | "杜绝CG塑料感、杜绝写实人脸、杜绝暗调锐利阴影" |

## 第五部分：AITANG 5维约束（视频层叠加约束）

### 用途
在6段式提示词之外，用5个维度对视频生成器做全局约束。2声明+6段式是"写什么"，5维约束是"怎么保证AI不跑偏"。

| 维度 | 解决什么 | 核心写法 |
|------|---------|---------|
| 1.分镜与动作逻辑 | 镜头顺序和动作蓝图 | "使用故事板@图片X为权威来源，从左到右依次遵循，不得重新诠释" |
| 2.时长与节奏 | 压缩比和剪辑节奏 | "N镜头压M秒，每节拍=动作快照不是冗长动作，最终节拍前不松懈" |
| 3.角色与物理细节 | 动态物理感 | "呼吸/肌肉紧绷/毛发飘动/汗水/材质变形——写可感知的物理反应" |
| 4.场景与镜头风格 | 环境氛围+运镜 | "氛围词+光源+材质+质感(4层) + 具体角度+运动+光影" |
| 5.最终节拍 | 定格收尾 | "定格3秒，与故事板最后一格一致" |

### 5维 vs 6段式的关系

6段式是**每一条视频提示词的内部结构**（从运镜到风格），5维约束是**跨镜头的全局规则**（保证所有镜头服从同一逻辑）。两者互补，不重复：

- 6段式解决"这一镜怎么写"
- 5维约束解决"这些镜怎么串起来才不会跑偏"

## 第六部分：完整视频提示词模板（可直接套用）

### 模板A：标准视频（有角色+有故事）

```
【蓝图声明】使用故事板@图片X作为[N秒]视频的完整视觉和动作来源，从左到右依次遵循所有[N]个镜头；不得重新诠释动作、姿势、镜头角度或能量递进，需保留故事板的镜头顺序、构图多样性和最终定格姿势。

【节奏声明】将完整的[N]镜头序列压缩到[N]秒，每个节拍必须清晰呈现为动作快照，不能是冗长拖沓的动作；使用紧凑节奏+快速剪辑+流畅转场，最终节拍前不松懈不停顿。

【段1·运镜开场】[景别+角度]。镜头从[起点]以[速度]沿[路径]运动至[终点]，用时[N秒]。[对焦位置+景深]。此运镜的叙事目的是[为什么这么动]。

【段2·主体锚定】参考角色@图片1：[角色锚定词全文]。初始姿态：[身体朝向+重心+四肢位置]。表情：[五官逐一写+量化]。服装道具：[材质+反光+动态]。物理特征：[毛发/皮肤/肌肉的物理状态]。

【段3·时间线演进】0-[X]秒：[画面状态+谁在做什么+什么在变化]。[X]-[Y]秒：[动作细节：发力起点→路径→终点→用时]。[关键元素从A到B的完整变化轨迹——不要[常见错误]，而是[精确要求]]。

【段4·环境与氛围】前景：[质感细节]。中景：[主体位置]。远景：[氛围定调]。环境动态：[非主体运动元素+速度+频率]。光线：[7列光线变化表]。色彩：[色相/饱和度/明度变化]。声音暗示：[画面中能听到的元素]。

【段5·声音提示】环境音：[场景背景声][音量层级]。动作音：[动作触发声][音量层级]。情绪音：[氛围声音][音量层级]。音量曲线：[从pp到ff的变化过程]。

【段6·风格约束】渲染：[具体方式]。色彩调性：[具体色相+饱和度+对比度]。镜头质感：[机身+颗粒+画幅]。参考锚定：[风格参考词+@图片]。反向约束：[杜绝什么——至少3条]。
```

### 模板F：六段式微距（单镜头微观写法）

**适用**：FPV微距、产品特写、自然微观

**结构**：
1. **镜头基础信息**：焦段/光圈/景深/FOV
2. **场景信息**：环境/材质/灯光方向/色温
3. **运动信息**：镜头运动/主体轨迹
4. **主体物理时间互动**：物理细节（弹性/粘性/张力）+ 时间节奏（快/慢/变速）+ 主体与环境互动
5. **细节**：微观纹理/光影粒子/材质反射
6. **收尾**：定格/淡出/情绪落点

**与标准框架的关系**：宏观用标准框架拆分镜，微距镜头内部用六段式填充

### 模板G：爆炸拆解（产品/结构展示）

**适用**：产品拆解、工业展示、结构动画

**提示词结构**：
```
请基于首帧与尾帧，生成一段从"完整状态"平滑过渡到"爆炸拆解状态"的动画。

主体是【主体名称】。视频开始时，主体处于完整、未拆解状态，画面稳定、主体清晰、质感高级。随后主体按照真实结构逻辑逐步拆解展开——不要瞬间炸开，也不要杂乱乱飞，而是有节奏地分层分步展开。先拆外部大件，再逐步露出并分离内部结构、核心组件、中型部件、小型零件或细节元素。所有部件向上、向下、向左右、向前后多方向展开，形成层次丰富、错落有致、铺满整个画面的exploded view爆炸拆解效果。

拆解过程要强调：
1. 结构逻辑真实清晰
2. 动作平滑自然，有节奏感
3. 大件先分离，小件后展开
4. 不是爆炸乱飞，而是有秩序地悬浮展开
5. 画面始终保持高级、干净、清晰、震撼

镜头语言：镜头平稳流畅，可轻微推进、拉远、环绕或旋转，始终围绕主体展开，突出空间层次与结构之美。转场自然顺滑，带轻微慢动作质感，像高端广告或工业设计展示片。最终停留在尾帧的完整拆解状态，所有部件清晰悬浮排列，形成一张丰富、精密、满画幅、错落有致的拆解海报式画面。

整体风格：高端广告质感，电影级灯光，细节清晰，材质真实，空间纵深强，画面高级、精密、震撼。

禁忌：不要人物，不要手，不要杂乱背景，不要低清晰度，不要卡通风，不要错误结构，不要无序乱飞。
```

**核心技法**：反面约束+正面指令配对——"不要瞬间炸开，也不要杂乱乱飞，而是有节奏地分层分步展开"

## 第八部分：实战案例速查

### 案例1：小铃铛30s（3分镜·3D毛绒绘本风）

**核心数据**：3分镜 / 30秒 / 3D Pixar毛绒渲染 / 马卡龙暖色调
**情绪线**：生气→调节(1-2-3+摇尾巴+深呼吸)→平静
**关键技法**：
- 角色锚定词全程不变（100+字外观描述复制到每镜）
- 铃铛从"静止→摇晃→发光→划弧线"贯穿3镜做情绪锚点
- 11维全覆盖+镜头参数摘要每镜独立
- 反差点写法："可爱但紧张——萌物发怒的违和感"

### 案例2：外星飞船10s（5分镜·写实科幻风）

**核心数据**：5分镜 / 10秒 / IMAX胶片质感 / 暗调高反差
**情绪线**：日常→窒息→极静定格
**关键技法**：
- 完整4步工作流（11维→故事板→5维约束→提示词）
- 故事板5格带6色箭头标注
- 蓝图声明+节奏声明完整使用
- 压迫感递进：每2秒一个节拍，从"车流正常"到"全城熄灯"
- 最终节拍：定格3秒，绝对静默收尾

### 案例3：梦幻天象16s（4分镜·奇幻唯美风）

**核心数据**：4分镜 / 16秒 / 唯美数字艺术 / 深蓝+粉+金
**情绪线**：觉醒→聆听→凝望→召唤
**关键技法**：
- 11维场景描述用表格形式（快速对照）
- AITANG 5维约束用表格（A动作/T运镜/A时长/N情感/G节奏）
- 节奏曲线可视化（ASCII图表）
- 双版本提示词：整体版（文生视频一条16s）+ 分段版（图生视频每段4s）
- 英文提示词（适配Kling等国际平台）

### 案例4：爆炸拆解（产品展示·用户补充）

**核心数据**：首帧→尾帧动画 / 高端广告质感
**情绪线**：完整→有序拆解→震撼定格
**关键技法**：
- 反面约束+正面指令配对贯穿全程
- 过程分步写死（先外后内、大件先小件后）
- 最终状态清晰描述（"所有部件清晰悬浮排列"）
- 镜头语言给选项但限范围（"可轻微推进、拉远、环绕或旋转"）

## 第十部分：质量自检清单

写完提示词后，逐项检查：

- [ ] **蓝图声明**：是否声明了故事板为权威来源？
- [ ] **节奏声明**：是否声明了压缩比和节奏要求？
- [ ] **每秒有动作**：时间线是否覆盖完整时长，不留空白？
- [ ] **动作有细节**：是否写了发力起点→路径→终点→用时？
- [ ] **表情有量化**：是否五官逐一写+变化幅度？
- [ ] **空间有层次**：是否写了前景+中景+远景？
- [ ] **光线有方向**：光源位置+光色+光质+方向？
- [ ] **色彩有数值**：色相/饱和度/对比度是否具体？
- [ ] **速度有数字**：是否用秒数代替"缓缓/慢慢"？
- [ ] **反面有配对**：关键动作是否嵌入了"不要X，而是Y"？
- [ ] **角色锚定词**：是否完整复制角色板描述，未缩写？
- [ ] **反向约束**：是否至少3条具体禁止项？
- [ ] **无模糊形容词**：是否已消除"高级/好看/震撼/缓缓/微微"？
- [ ] **5维约束**：分镜逻辑/时长节奏/物理细节/场景镜头/最终节拍是否齐全？

# 剧本输入模板

定位：导演台工作流的标准化输入格式。用户提交剧本时，按此格式书写，导演台从第1步接收剧本，第2步生成导演脚本，后续继续走全链路。

---

## 模板格式

```
《[作品名]》
**类型**：[类型标签，如 古风 / 穿越 / 爽文漫剧]
**时长建议**：[如 60–90秒]
**基调**：[如 热血 × 盛唐史诗感 × 爽点节奏]

【序幕】
【[时代] · [地点] · [时间]】
[环境描写：光影/氛围/声音]
[角色名]（[性别]，[年龄]），[状态描述]。
[动作/事件]。
[台词或旁白]。

【第一幕】
【[时代] · [地点] · [时间]】
[场景描写]。
[角色动作]。
[角色名]：
"[台词]"
[情绪/状态标注]。

【第二幕】
（同上格式）

【第三幕】
（同上格式）
```

---

## 实际示例：《我在盛唐写天下》

```
《我在盛唐写天下》
**类型**：古风 / 穿越 / 爽文漫剧
**时长建议**：60–90秒
**基调**：热血 × 盛唐史诗感 × 爽点节奏

【序幕】
【现代 · 深夜办公室】
键盘声急促。电脑屏幕蓝光刺眼。
沈昭昭（女，28岁），面色苍白，伏案加班。
手机提示音不断。
她抬头，视线模糊——
黑屏。

【第一幕】
【盛唐 · 金銮殿 · 日】
鼓声震天。
沈昭昭猛然睁眼，已跪在大殿中央，身着男装官服，双手被押。
百官列立，殿宇巍峨。
大臣厉声：
"大逆不道！假称诗才惊世，欺君罔上，当斩！"
沈昭昭震惊低语：
"这是……唐朝？"
龙椅之上，皇帝目光沉沉。
皇帝：
"既言才华盖世，当殿作诗。若不能——斩。"
刀光映入她瞳孔。
大殿死寂。

【第二幕】
沈昭昭缓缓起身。
呼吸渐稳。
她望向殿外——
长安城阳光万里。
她低声：
"既来盛唐——便与盛唐争一争。"
抬头，高声吟诵：
"君不见黄河之水天上来——"
声音回荡大殿。
群臣震动。
皇帝缓缓站起。
诗声激昂，如惊雷落殿。

【第三幕】
殿外风起。
长安街市灯火连绵。
皇帝低声：
"此诗，当传万世。"
沈昭昭目光坚定。
她轻声自语：
"既然来了……那便写尽三万里长安。"
镜头推远。
盛唐山河展开。
```

## 格式要素说明

| 要素 | 作用 | 导演台如何使用 |
|------|------|--------------|
| 类型标签 | 锁定视觉风格方向 | 决定11维框架的世界观维度和风格锚定词 |
| 时长建议 | 锁定总时长 | 计算每幕分配时长，控制分镜数量 |
| 基调 | 锁定情绪总基调 | 决定情绪弧线的起点和终点 |
| 序幕 | 建置/日常状态 | 建立角色日常，与后续形成反差 |
| 各幕结构 | 冲突→高潮→解决 | 拆解为三幕，标注转折点强度 |
| 场景标题 | [时代·地点·时间] | 直接映射到场景设计 |
| 环境描写 | 氛围/光影/声音 | 映射到11维框架的光线/色彩/氛围维度 |
| 角色描写 | 外貌+状态+动作 | 提取角色设定卡信息 |
| 台词 | 对话+旁白 | 标注标点语气控制，映射到配音环节 |
| 情绪标注 | 角色内心状态 | 映射到情绪弧线和表情量化写法 |

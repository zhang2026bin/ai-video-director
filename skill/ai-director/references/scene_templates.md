## 一、通用场景模板

### 模板1：人物+大场景
```
【风格】+【画质】
【人物】谁，穿什么，什么姿态，什么表情
【环境】在哪里，什么建筑/自然景观
【构图】什么镜头角度，什么引导线
【对比】渺小人物vs宏大场景
【光影】什么光源，什么色调
```

### 模板2：神兽/生物
```
【风格】+【画质】
【主体】什么神兽
【细节】鳞片/毛发颜色，眼睛特征，角/翅膀细节
【动作】什么动作，什么姿态
【环境】在什么环境
【真实感】鳞片高光、毛发层次、光影统一
```

### 模板3：文化IP视频
```
【基本信息】多少秒动态视频
【风格定位】极繁主义史诗级XX杰作
【运镜方式】什么运镜
【核心场景】什么地方，有什么奇观
【文化元素】具体非遗/传统技艺细节
【核心主体】谁/什么神兽
【细节质感】材质/光影/纹理
```

### 模板4：情绪特写视频
```
【整体设定】风格+色调+画质
【分镜1】开场特写，局部细节
【分镜2】面部微表情变化，按时间写清楚每个阶段
【分镜3】关键动作特写，细节写死
【分镜4】收尾拉远，定格画面
【负面排除】不要夸张，不要大幅度动作
```

## 二、AIGC导演级分镜五要素框架

适用于需要极高精度的复杂场景（特效大片/生物/玄幻）

```
【1. 摄影机与光学设定】
- 具体视角（FPV/第一人称/上帝视角等）
- 镜头焦段（超广角/长焦/微距等）
- 镜头距离（紧贴/远距离/中景等）
- 特殊光学效果（动态模糊/浅景深/光晕等）
- 视角运动（滚转/俯仰/环绕等）

【2. 运动动力学】
- 速度感（超高速/慢动作/变速切换）
- 运动轨迹（直线/非线性/俯冲/盘旋等）
- 残影效果（半透明/拖尾等）
- 速度切换节点（什么时刻变速）
- 参照物运动（背景如何相对运动）

【3. 环境与物理交互】
- 场景具体搭建（什么环境、有什么元素）
- 物体材质与质感描述
- 穿透/碰撞/接触的具体效果
- 流体/粒子/布料等物理效果
- 重力、张力等物理规律体现

【4. 灯光与材质】
- 整体配色方案
- 主光源位置与色调
- 轮廓光/环境光/反射光设计
- 关键材质的光学属性（次表面散射/镜面反射/折射等）
- 通透度、光泽度、纹理细节

【5. 感官与情绪】
- 整体风格定位
- 视觉体验描述
- 氛围基调
- 感官融合（视觉+听觉+触觉联想）
- 最终画面情绪目标
```

## 三、模块化组合公式

### 叙事节奏公式
```
【开场】= 特写镜头 + 局部细节 + 埋下悬念
【发展】= 中景拉远 + 环境交代 + 动作展开
【高潮】= 大特写 + 微表情极致 + 关键动作
【收尾】= 全景拉远 + 环境呼应 + 情绪留白
```

### 镜头节奏公式
```
慢 → 快 → 慢
特写 → 中景 → 特写 → 全景
静 → 动 → 静
```

### 情绪递进公式
```
克制 → 动摇 → 失控 → 释放 → 平静
```

## 四、短剧爽点模板（逆袭打脸）

```
镜头1（0-2s）：低角度仰视+快速推入，聚焦主角握紧的拳头
镜头2（2-4s）：环绕旋转镜头，360度环绕主角，英雄登场
镜头3（4-6s）：快速变焦群镜头，众人震惊面部特写快切
镜头4（6-8s）：终极技拉升镜头，主角亮出关键物品，镜头急速后上方拉升
镜头5（8-10s）：慢动作定格，反派表情从嚣张到错愕到惊恐
```

## 五、女频浪漫风专属模板

### 核心要素
```
【人物】五官精致、长发飘逸、飘逸长裙/蕾丝/丝绸
【场景】花海/水边/古建筑/梦幻（月光/星空/云雾）
【布光四件套】轮廓光+发丝光+柔光镜+小景深
【运镜】缓慢环绕+推近特写+跟拍走动+低角度仰拍
【色调】暖粉/暖金+柔和渐变+轻微颗粒感+丁达尔效应
```

### 质感关键词
```
现实主义，电影光线
半透明纹理，哑光高级质感
动态柔光投影，朦胧发光层
布料质感通透细腻带细闪
皮肤真实纹理，不假面
```

## 六、分镜时间轴写法标杆

### 示例：古风女子出嫁（情绪递进）
```
0-3秒：极近景特写，手指抚过红色嫁衣刺绣，手指颤抖
3-6秒：中景到面部特写，缓慢推近，强颜欢笑
6-9秒：面部大特写，眼眶泛红，泪腺分泌
9-12秒：固定特写，拼命眨眼憋泪
12-15秒：慢镜头，眼泪滑落跟拍，右眼先落泪
收尾：镜头缓慢拉远，背影，红色嫁衣微微晃动
```

### 示例：天地棋局（玄幻特效）
```
0-2秒：近距特写，棋盘纹理，焦点转切到白裙女子侧脸
3-4秒：特写捻棋指尖，棋子轻旋，眼神骤变
5-10秒：棋子触盘→冲击波→大地崩裂→天地化棋盘
收尾：山川归位，光晕消散，定格全景
```

# AI视频编导方法论

> 解决的核心问题：从"特效演示"升级为"有故事的画面"。所有方法服务于AI短视频/短片/漫剧的剧本创作和分镜设计。

---

## 一、故事结构框架

### 1.1 因果链 > 时间链

**核心原则**：好故事用因果链推进，不是时间链。

| 类型 | 特征 | 观众反应 | 示例 |
|------|------|----------|------|
| 时间链（差） | A happened → then B → then C | "然后呢？没了？" | 早上起床→出门→遇到同事→下班 |
| 因果链（好） | Because A → so B → because B → so C | "接下来会怎样？" | 因为迟到（A）→所以走小路（B）→因为小路遇到事故（C）→所以成为目击者（D） |

**自检**：每个场景是否既是上一个的结果，又是下一个的原因？如果一个场景删掉不影响前后，这个场景就是多余的。

### 1.2 三幕式（适配AI短视频）

| 幕 | 占比 | 功能 | 必须包含 |
|----|------|------|----------|
| 第一幕：建置 | 15-25% | 建立世界+角色+核心矛盾 | 触发事件（打破日常的那一下） |
| 第二幕：对抗 | 50-60% | 冲突升级+转折+递进 | 至少2个情节点+1个中间反转 |
| 第三幕：结局 | 15-25% | 高潮+解决+余韵 | 终极选择+角色变化可见 |

**10秒视频极简三幕**：
- 0-2秒（建置）：状态呈现+触发
- 2-7秒（对抗）：冲突+转折+递进
- 7-10秒（结局）：高潮+定格

### 1.3 英雄之旅（适配品牌故事/人物传记）

核心4步（不必12步全用）：
1. 日常世界 → 2. 冒险召唤（打破平衡的事件） → 3. 试练与蜕变 → 4. 带着新自我回归

## 二、冲突设计（故事的发动机）

### 2.1 三层冲突模型

每个好故事至少要有2层冲突同时存在：

| 层级 | 定义 | 示例 |
|------|------|------|
| 外部冲突 | 人与环境/他人/物理障碍 | 机甲vs敌方堡垒 |
| 内部冲突 | 角色自身矛盾（想要A但害怕B） | 想撤退但必须掩护队友 |
| 哲学冲突 | 更深层的价值对立 | 个人生存vs集体利益 |

**自检**：如果只有外部冲突（打怪），没有内部或哲学冲突，故事就是扁平的动作片。

### 2.2 冲突升级公式

冲突必须递进，不能一步到位：

```
初始障碍（小阻力）→ 挫折/失败（情况恶化）→ 代价升级（赌注更高）→ 终极对抗（全力一搏）
```

**10秒视频冲突升级**：
- 障碍出现（敌方反击）→ 情况恶化（弹药不足/受伤）→ 最后一击（赌上一切）

### 2.3 对手设计

**没有对手就没有戏剧张力。** 即使是环境类/抽象类视频，也必须设计"对抗力量"。

对手类型：
- 具象对手：敌人/怪兽/竞争对手
- 环境对手：风暴/时间/距离
- 抽象对手：恐惧/偏见/系统

**对手必须有的要素**：
- 明确的存在感（不能是模糊的背景）
- 能造成真实威胁（不能是一打就死）
- 有反击能力（不能只是被动挨打）

## 三、钩子设计（留住观众）

### 3.1 钩子类型

| 类型 | 定义 | 示例 | 适用位置 |
|------|------|------|----------|
| 悬念钩子(INFO) | 提出一个观众想知道答案的问题 | "他手里握着什么？" | 开场 |
| 命运钩子(FATE) | 让观众担心角色会遭遇什么 | "她能逃出去吗？" | 中段 |
| 反转钩子(TWIST) | 打破观众预期的信息 | "原来敌人是他" | 结尾/转折 |
| 情感钩子(EMOTION) | 让观众产生强烈共情 | 角色在绝望中不放弃 | 全程 |

### 3.2 钩子布局规则

- 开场5%必须出钩子（前2秒决定观众走不走）
- 中段必须升级钩子（不是重复，是加码）
- 结尾必须留半结果（不完全解决，引向下一集或余韵）

**10秒视频钩子布局**：
- 0-1秒：视觉钩子（异常画面/强烈对比）
- 3-5秒：命运钩子（对手反击/情况恶化）
- 9-10秒：半结果（定格/留悬念/暗示更大世界）

## 四、情绪弧线构建

### 4.1 情绪曲线设计

**核心原则**：情绪必须有起伏，不能平。

好的情绪曲线：
```
     高潮
    /    \
   /      \   余韵
  /        \  /
 /    低谷\/
/
建置
```

坏的情绪曲线：
```
/\/\/\/\/\/\ （太平，没有递进）
或
\__________/ （先低后高，没有起伏）
```

### 4.2 情绪递进五档

| 档位 | 情绪状态 | 持续时长 | 用法 |
|------|----------|----------|------|
| 1 | 平静/日常 | 10-15% | 开场建置，不能太久 |
| 2 | 好奇/紧张 | 20-25% | 触发后递进 |
| 3 | 揪心/焦虑 | 20-25% | 冲突升级 |
| 4 | 爆发/震撼 | 15-20% | 高潮 |
| 5 | 释然/回味 | 10-15% | 结尾余韵 |

**自检**：如果全片在同一档位，就是平的。至少要有3个不同档位。

### 4.3 留白规则

- 高潮之后必须有留白（让观众消化）
- 连续高不能超过总时长30%（观众会麻木）
- 留白不是没内容，是"安静但有信息"（空镜+环境音+角色微动作）

## 五、节奏设计

### 5.1 镜头时长节奏（适配AI视频）

| 功能 | 单镜时长 | 适用场景 |
|------|----------|----------|
| 环境铺垫/空镜 | 2-4秒 | 开场、转场、结尾 |
| 常规叙事 | 1.5-3秒 | 对话、互动、推进 |
| 高潮快切 | 0.5-1.5秒 | 冲突爆发、动作戏 |
| 情绪落点/定格 | 3-6秒 | 结尾、转折后 |
| 慢镜头 | 按实际1.5-2倍 | 关键动作放大 |

### 5.2 全片节奏公式

```
慢（建置）→ 中（发展）→ 快（高潮）→ 慢（结尾）
```

**10秒视频节奏**：
- 0-3秒：中速（信息密度适中）
- 3-5秒：加速（冲突出现，镜头变短）
- 5-8秒：最快（高潮段落，0.5-1秒切）
- 8-10秒：骤停（定格/慢镜/留白）

### 5.3 节奏变化技巧

- **加速**：缩短单镜时长+增加信息密度+提高音量/音效频率
- **减速**：拉长单镜+减少信息+降低音量/慢动作
- **骤停**：快节奏后突然静止（冲击力最大）
- **变速**：快→慢→快（制造不安感）

## 六、动作场景专项（10秒战斗/追逐/变形）

### 6.1 动作场景叙事结构

**动作场景不是特效堆砌，必须有叙事弧线**：

```
起（开打/启动）→ 经（劣势/转折）→ 果（胜负+代价）
```

**必须有**：
- 明确的对手/威胁
- 至少一次反转（差点输了/意外发现弱点）
- 胜利有代价或失败有余韵（不能只是打赢了就完了）

### 6.2 变形场景专项

**变形聚焦机体自身**，环境不变形。

变形要素清单：
- 装甲板块翻转/重组/锁合
- 武器折叠缩回→新武器展开锁定
- 涂装层翻起脱落→露出底层
- 关节重新排列→体型变化
- 液压管线重新连接→排气口迁移
- 内部结构暴露→重新封闭

变形节奏：快-慢-快（启动快→中间细节展示慢→锁定完成快）

### 6.3 跟弹/追踪镜头专项

**不能只是直线飞行**，必须有障碍和变化：
- 穿越障碍物（建筑残骸/拦截弹/碎片）
- 地形变化（平地→峡谷→城市）
- 速度变化（加速→险避→再加速）
- 目标逐渐清晰（远景模糊→近景细节）

### 6.4 爆炸/命中场景专项

**不能一炸了之**：
- 撞击前有最后悬念（能不能打中？）
- 爆炸分层次（闪白→火球→冲击波→碎片→尘幕）
- 爆炸后有变化（环境改变/新信息暴露/角色状态变化）
- 二次事件（坍塌/暴露核心/二次爆炸/对手现身）

## 七、角色设计（从剧本推导）

### 7.1 角色叙事属性 → 视觉属性

| 叙事属性 | 对应视觉属性 | 示例 |
|----------|-------------|------|
| 身份/职业 | 服装类型、装备、体态 | 军人→战术装备+挺立体态 |
| 性格 | 配色、材质、线条 | 冷酷→深色系+硬线条+金属质感 |
| 动机 | 标志性道具/伤痕 | 复仇→身上有旧伤疤 |
| 内在矛盾 | 冷暖色对比/新旧对比 | 善良战士→冷硬外壳+温暖眼神 |
| 角色弧线 | 服装/造型前后变化 | 从破烂→完整（成长）|

### 7.2 角色辨识度

一个让观众一眼认出的特征就够：
- 视觉记忆点：独特配色/标志性道具/异常比例
- 行为记忆点：习惯性动作/特殊步态/标志性姿势
- 声音记忆点：口头禅/独特音色/语速特征

## 八、自检清单（每次写剧本/分镜必过）

### 故事层
- [ ] 因果链是否成立？（每个场景是前因后果）
- [ ] 核心冲突一句话说得清？
- [ ] 至少有2层冲突（外部+内部/哲学）？
- [ ] 对手/威胁是否明确且有存在感？
- [ ] 冲突是否递进升级（不是一步到位）？

### 情绪层
- [ ] 情绪弧线是否有明显起伏？（不是平的）
- [ ] 至少有3个不同情绪档位？
- [ ] 高潮前是否有铺垫递进？
- [ ] 高潮后是否有留白？
- [ ] 是否有至少一个"屏息瞬间"？

### 节奏层
- [ ] 全片是否遵循慢→中→快→慢？
- [ ] 高潮段落镜头是否比铺垫段更短？
- [ ] 是否有"骤停"瞬间？
- [ ] 单镜时长是否合理（不超过10秒）？

### 钩子层
- [ ] 前2秒是否有视觉/信息钩子？
- [ ] 中段是否有钩子升级？
- [ ] 结尾是否有半结果/悬念？

### 动作场景专项（如有）
- [ ] 动作是否有叙事弧线（起→经→果）？
- [ ] 对手是否有反击？
- [ ] 变形是否聚焦机体自身（环境不变）？
- [ ] 跟弹是否有障碍和变化？
- [ ] 爆炸后是否有变化/二次事件？

## 九、场景级叙事思维（2026-07-21新增）

> 核心洞察：不要把秒数看得那么重要，把一小段的叙事画面给完善好。——来源：用户观察《绿皮书》镜头切换手法

### 9.1 问题诊断：AI视频的"参数化陷阱"

**现状**：大部分AI视频创作者过度关注"时长控制"（精确到秒），而忽视了"叙事完整性"。

**典型错误**：
- 每个镜头孤立设计，先定死"这个镜头3秒"，然后往里塞内容
- 为了凑时长硬塞画面，或为了精确到秒反复调参数
- 把"画面好看"当目标，而不是"讲故事"
- 镜头之间没有整体叙事逻辑，像高级幻灯片

**结果**：技术达标但叙事破碎，观众看完记不住任何东西。

### 9.2 场景级思维：从"镜头"到"场景"

**核心原则**：镜头切换服务于情绪和叙事，不是技术参数。

**电影镜头语言实证**（来自《绿皮书》等经典电影）：
- **5-7秒**：常规节奏，让观众看清画面、理解信息
- **3秒**：加速，制造紧张感或切换情绪
- **17-20秒**：延展，让观众沉浸在一个重要时刻里

**关键认知**：每个时长的选择都有**叙事理由**，不是随意设定。

### 9.3 场景级思维的三层框架

#### 第一层：情绪优先，时长其次

**错误流程**：
```
定死时长（3秒）→ 往里塞内容 → 调整参数适配时长
```

**正确流程**：
```
确定情绪目标 → 设计叙事画面 → 根据内容自然分配时长
```

**示例**：
- ❌ "这个特写镜头3秒"（参数先行）
- ✅ "这个角色需要从抗拒到接受的情绪转变，给足时间让观众看到变化"（情绪先行）

#### 第二层：场景完整性 > 镜头数量

**核心**：一个场景必须传达完整的情绪/信息，不能因为"时间到了"就强行切镜。

**自检**：
- 这个场景要传递什么情绪/信息？
- 这个情绪/信息是否传达完整了？
- 如果没传达完整，是时长不够还是设计有问题？

**示例**（《绿皮书》经典场景）：
- 角色在车里从抗拒到接受：不是"3秒切一个镜头"，而是"让观众完整看到这个情绪转变过程"
- 可能用一个5-7秒的长镜头，也可能是2-3个镜头的组合，但必须传达完整的情绪弧线

#### 第三层：镜头切换的叙事理由

**每个镜头切换都必须回答**：
- 为什么要切？（情绪变化？信息更新？视角转换？）
- 切到哪里？（更近？更远？不同角度？）
- 切完之后观众应该感受到什么？

**镜头切换的叙事功能**：
| 切换类型 | 叙事功能 | 示例 |
|---------|---------|------|
| 全景→中景 | 从环境到人物，建立关系 | "这是他的世界"→"现在看他的反应" |
| 中景→特写 | 情绪升级，聚焦细节 | "他在想什么？"→"看他的眼神" |
| 特写→全景 | 情绪释放，空间扩展 | "他的内心"→"他所在的世界" |
| 同景别切换 | 时间推进，动作连续 | "第一步"→"第二步"→"第三步" |

### 9.4 实操：场景级分镜设计法

#### 步骤1：先写"场景目标"，不写"镜头列表"

**错误做法**：
```
镜头1：3秒，中景，角色站着
镜头2：3秒，特写，角色表情
镜头3：3秒，全景，角色走远
```

**正确做法**：
```
场景目标：展现角色从犹豫到决定的内心变化
- 开场：角色站在十字路口，环境冷清（建立孤立感）
- 中段：角色低头看手中的信，手指颤抖（犹豫的细节）
- 转折：角色抬头，眼神从迷茫变为坚定（决定时刻）
- 结尾：角色迈步向前，镜头跟随（行动开始）
```

#### 步骤2：根据场景目标，自然分配镜头

**从场景目标推导镜头**：
```
场景目标：展现角色从犹豫到决定

镜头1（5秒）：全景，角色站在十字路口，环境冷清
  → 叙事功能：建立孤立感，让观众看到"他面临选择"
  
镜头2（7秒）：特写，角色低头看信，手指颤抖，眼神犹豫
  → 叙事功能：展现内心挣扎，让观众感受到"他在犹豫什么"
  
镜头3（3秒）：近景，角色抬头，眼神变化
  → 叙事功能：转折时刻，让观众看到"他决定了"
  
镜头4（5秒）：中景，角色迈步向前，镜头跟随
  → 叙事功能：行动开始，让观众感受到"他要出发了"
```

#### 步骤3：检查叙事完整性

**自检清单**：
- [ ] 每个场景是否有明确的情绪/信息目标？
- [ ] 这个目标是否在这个场景中完整传达了？
- [ ] 镜头切换是否有叙事理由（不是随意切）？
- [ ] 如果删掉某个镜头，是否影响叙事完整性？（影响=必要，不影响=多余）
- [ ] 观众看完这个场景，是否能感受到预设的情绪/信息？

### 9.5 学术与工业界验证

#### FilMaster（ICLR 2026论文）
- **团队**：港大+快手+微软+清华
- **核心观点**："现有AI视频系统产生的是模板化视觉和不吸引人的叙事"
- **解法**：场景级RAG——把一个完整场景（包含多个镜头）作为统一查询，从44万部真实电影片段里学习镜头语言
- **启示**：镜头不是孤立的，是场景的一部分

#### SmartDirector（优酷木可实验室）
- **核心观点**："视频生成差的不是画面，是讲故事的能力"
- **解法**：把关键帧当成分镜故事板，让AI精确还原创作者预设的叙事节奏
- **启示**：叙事节奏 > 技术参数

#### Wan 2.6（通义万相）
- **定位**："叙事型AI视频模型"
- **能力**：内置"好莱坞经典叙事逻辑引擎"，能理解故事逻辑、角色情绪、镜头节奏
- **启示**：行业正在从"生成画面"转向"生成故事"

### 9.6 与现有方法论的关系

**场景级叙事思维**是对现有方法论的补充，不是替代：

| 现有方法论 | 场景级思维补充 |
|-----------|--------------|
| 三幕式结构 | 每个"幕"内部也要有场景级完整性 |
| 情绪弧线设计 | 情绪弧线的每个"点"都是一个完整的场景 |
| 镜头时长节奏 | 时长是叙事的结果，不是叙事的约束 |
| 钩子设计 | 钩子的设置要服务于场景目标，不是为了钩子而钩子 |

### 9.7 总结：AI视频的正确思维

**错误思维**：
```
我要做一个30秒的视频 → 拆成10个镜头，每个3秒 → 往每个镜头塞内容
```

**正确思维**：
```
我要讲一个故事 → 故事有几个关键场景？→ 每个场景要传达什么？→ 根据场景目标设计镜头
```

**一句话总结**：**先把故事讲清楚，再考虑怎么拍。**

## 一、基础微表情（12种）

### 1. 忍泪初期
下眼睑向上收缩用力，眼白内眼角1/3变红

### 2. 咬唇克制
下唇被上排牙齿轻咬1毫米深度，唇缘因压迫泛白

### 3. 嘴角微撇
两侧嘴角同时向下微撇2-3毫米，幅度极小

### 4. 八字眉
眉头向内收缩形成八字眉，额头平滑无抬头纹

### 5. 眼泪滑落单眼
泪珠直径2毫米，从下睑内眼角溢出，2秒滑到下颌线，颧骨处停留0.5秒

### 6. 眼泪滑落双眼
右眼先落泪，左眼比右眼晚0.8秒，路径对称

### 7. 缓慢眨眼
闭眼0.5秒，睁眼0.5秒，眼睫毛沾细小泪珠

### 8. 空笑/假笑
颧大肌+眼轮匝肌同时参与但幅度压半，嘴角眼角只动一半

### 9. 笑容颤抖
嘴角上扬不稳定，高频微颤，一侧嘴角被向下牵引

### 10. 笑容破碎
嘴角从上扬缓慢坠落至水平，伴随不规则抽搐

### 11. 瞳孔微扩
瞳孔比正常状态放大10%

### 12. 手指微颤
手指每秒2-3次频率小幅度颤抖

## 六、使用方法

### 错误写法
```
他很害怕
她表情惊恐
他看起来很坚定
```

### 正确写法（从词库选取+量化）
```
他眉毛上扬、眼睛瞪大露出上方窄条巩膜、嘴巴微张、鼻翼收缩（惊恐瞪眼），额头冷汗在月光下反光
她眼眶泛红但眉头紧蹙、嘴唇抿紧、下巴肌肉紧绷（隐忍不哭），手指每秒2-3次频率小幅度颤抖
他牙关紧咬、太阳穴青筋微凸、眼神凶狠、鼻翼微微扩张（咬牙切齿），目光扫视前方保持警戒
```

### 原则
1. 不写笼统情绪词，从词库选具体面部细节组合
2. 五官逐一写：眉毛+眼睛+嘴巴+鼻翼+额头/下巴，至少写3个部位
3. 加量化：角度、距离、颜色变化
4. 加生理反应：冷汗、青筋、泛红、瞳孔变化

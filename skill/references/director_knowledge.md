# 导演专业素养速查

## 一、镜头语法

| 镜头类型 | 叙事功能 | 什么时候用 | 什么时候别用 |
|---------|---------|-----------|------------|
| 大远景 | 建立空间/孤独感/渺小感 | 开场、转折后重新定位 | 情感高潮（太远看不见脸） |
| 远景 | 展示人物与环境关系 | 角色进入新空间 | 需要看清表情时 |
| 中景 | 日常对话/动作展示 | 最通用的景别 | 需要极致亲密或极致疏离时 |
| 近景 | 情感传达/内心活动 | 角色做关键决定/情感爆发 | 动作戏（信息量不够） |
| 特写 | 强调细节/制造压迫感 | 关键道具/微表情/情绪极点 | 滥用会失去冲击力 |
| 超特写 | 极端强调/恐怖/抽象 | 瞳孔/唇/手指/纹理 | 日常叙事（太怪） |

## 二、运镜语法

| 运镜 | 叙事含义 | 典型场景 |
|------|---------|---------|
| 推近 | 聚焦/发现/压迫感 | 角色发现关键线索/情绪收紧 |
| 拉远 | 揭示/孤立/解脱 | 揭示全景/角色被抛弃/释然 |
| 横摇 | 观察/揭示 | 角色扫视环境/揭示新信息 |
| 跟拍 | 参与/紧迫 | 角色奔跑/追逐/探索 |
| 环绕 | 英雄感/困顿感 | 角色觉醒/角色陷入困境 |
| 升降 | 权力感/渺小感 | 俯视=被控制/仰视=被仰望 |
| 手持 | 纪实感/紧张感 | 战斗/混乱/纪实风格 |
| 固定 | 冷静/等待/凝固 | 等待中的焦灼/时间凝固感 |

## 三、景别序列规则

| 序列 | 含义 | 效果 |
|------|------|------|
| 远景→中景→近景 | 正常推进 | 聚焦/发现/深入 |
| 近景→远景 | 震惊/疏离 | 突然拉开距离/揭示全局 |
| 特写→特写 | 压迫/紧张 | 快速剪辑/信息轰炸 |
| 远景→远景 | 对比/平行 | 两个空间的并列 |
| 中景→特写→中景 | 强调后回归 | 突出细节后回到语境 |

## 四、色彩叙事

| 色彩 | 情绪含义 | 典型用法 |
|------|---------|---------|
| 暖橙/金色 | 温暖/怀旧/希望 | 回忆/家/黎明 |
| 冷蓝/青色 | 孤独/压抑/未来 | 深夜/科技/疏离 |
| 红色 | 危险/激情/暴力 | 警告/爱情/冲突 |
| 绿色 | 自然/病态/不祥 | 森林/毒药/诡异 |
| 黄色 | 快乐/病态/警告 | 阳光/腐烂/危险信号 |
| 消色/灰 | 绝望/记忆/虚无 | 末日/闪回/失去希望 |

**色彩转折技巧**：同一场戏从暖调变冷调=情绪急转（如团聚→争吵）

**角色专属色**：每个角色绑一个主色，观众一看色调就知道谁在场

**两套世界两套色调**：现实vs梦境/过去vs现在，用色调区分

## 六、剪辑节奏

| 节奏类型 | 每镜头时长 | 效果 | 典型场景 |
|---------|-----------|------|---------|
| 长镜头/慢剪 | 5秒+ | 沉浸/冥想/焦虑 | 文艺片/恐怖片/等待 |
| 常规节奏 | 2-4秒 | 流畅叙事 | 大部分叙事段落 |
| 快速剪辑 | 1-2秒 | 紧张/兴奋/混乱 | 动作戏/蒙太奇/高潮 |
| 极速剪辑 | <1秒 | 碎裂/失控/冲击 | 精神崩溃/爆炸/记忆闪回 |

**节奏铁律**：
- 快→慢的减速比慢→快的加速更有冲击力
- 安静是最大的音量——快节奏中插一个固定长镜头比再加快切更有力
- 剪辑点跟音乐节拍走，不跟画面走

## 七、音乐情绪映射

| 情绪 | 音乐特征 | 乐器倾向 |
|------|---------|---------|
| 紧张 | 不协和音+心跳节奏+渐强 | 弦乐群/合成器 |
| 悲伤 | 下行旋律+弱音+留白 | 大提琴/钢琴/单簧管 |
| 温暖 | 大调+柔和节奏+泛音 | 木吉他/竖琴/钢琴 |
| 史诗 | 铜管+打击乐+渐强 | 交响乐团+合唱 |
| 诡异 | 微音程+失真+反常节奏 | 特雷门琴/合成器/水琴 |
| 空灵 | 长音+混响+极简 | 人声/电子/环境音 |

## 八、氛围反差点公式

好的氛围不是单一情绪，是主情绪+反向裂隙：
- 温暖但孤独（家的灯光，窗外无人）
- 奢华但破败（金漆剥落的宫殿）
- 童真但诡异（微笑的布偶在暗角）
- 干净但危险（无菌实验室里的血迹）
- 精致但腐败（完美蛋糕上的霉斑）

## 九、叙事思维（写提示词=写小说）

**场景构图三层**：
- 前景：质感细节（近处物体的纹理/触感）
- 中景：主体动作（角色在做什么）
- 远景：氛围定调（环境传递的情绪）

**五感法**：
- 视觉：光影方向/色温/空气透明度
- 听觉暗示：画面中能"听到"的元素
- 触觉暗示：温度和质感
- 嗅觉暗示：场景特有气味
- 情绪氛围：用环境传递，不直接说

**人物小说笔法**：
- 不写"一个女人站着"，写"她微微侧身，风将碎发吹过半阖的眼"
- 微表情>大动作：攥紧的指节/移开的目光/抿住的下唇
- 动作要有动机：不是"手举起来"，是"指尖触碰到门框时犹豫着停住"

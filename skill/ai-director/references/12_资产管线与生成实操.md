## 第一讲 · 资产管线（谁来演、在哪演）

### 1. 资产普查（开拍前第一件事）

通读剧本，按四类登记，**宁可多列不可遗漏**：

| 类型 | 识别信号 | 技术路径 |
|---|---|---|
| 角色 | 人名、人称、身份称谓 | 最难：面部一致 + 多状态 + 三视图 |
| 场景 | 地点名词、环境描写 | 中：多视角 + 状态版本，无面部一致性 |
| 物品 | 具体物件（石棺、断矛） | 易：单张图、提示词简洁 |
| 生物 | 妖兽、灵宠、虚影 | 中低：一致性要求较低 |

**状态标注**（比资产本身更容易漏）：
- 角色：受伤版、浴血版、被绑版、换装版
- 场景：正常版、破坏版（只写"破坏后的静态结果"，不写"被震碎了"这个动作）
- 区分：**状态**=剧情导致的外观变化（伤口、血迹）；**造型**=主动的服装/发型变化

**清单即外部化记忆**：把剧本原文描述搬进平台描述栏，制作时逐条执行，不回头翻剧本。

### 2. 风格定调（视觉宪法）

- 题材→风格映射：现代都市→真人写实；古装仙侠→真人写实古风玄幻；卡通→二次元/三渲二；玄幻修真→真人写实+奇幻特效
- **风格 ≠ 画质**：风格是方向决策，画质是技术参数
- **主力模型只选一个**，不频繁换（换模型 = 风格漂移的主因）；换之前先做完一批资产

**四层提示词模板**（每次生成都套）：
```
[风格层] 固定不变：真人写实，古风玄幻，电影级光影，超高清
[主体层] 随资产换：角色名 + 身份
[细节层] 随需求换：面部特征 + 服装材质 + 表情状态
[技术层] 按制作定：三视图/正面 + 景别 + 比例
```

### 3. 角色生成五步

1. **AI 人物分析**：把剧本段落+风格要求给 LLM，要它输出形象描写（作用：语义缓冲层，避免凭偏好脑补）
2. **筛选改写**：AI 输出是素材不是成品——删掉会带偏的词（如"忠义良将"会导向武将铠甲）
3. **文生图**：手动模式，检查五要素（主体/风格/负面/背景/构图）
4. **三视图公式**：`干净白色网格背景 + 三视图 + 面部特写 + 16:9`
5. **多状态派生**：面部描述完整复制，只改状态字段；用**关联资产**（不是垫图）

**负面约束是刚需**：古风+男性+战斗 在训练数据里高度关联铠甲，不加"不要铠甲"，基础形象就会穿甲，后续所有状态继承错误。

**关联资产 vs 垫图**：
- 垫图 = 像素级复制 → 姿势和构图被锁死
- 关联资产 = 身份特征向量 → 神似形不同，姿势可自由变化

**视觉化翻译**：文学描述→可见元素。"经脉近断修为被废"→"面色苍白、嘴角溢血、精神萎靡"。
**AI 消除**：局部冗余元素（多出来的石头）直接涂抹删除，别整张重生成。

### 4. 场景与物品

- **角色要白底，场景要环境**：场景提示词里**禁止**写"背景为白色"（会像贴图浮在画面上）
- 场景必须写：地点、氛围、色调、标志性物体、**空间尺度**
- **空间尺度按人数定**：8 人同框 → 写"空旷宏大、能容纳八人"，否则 AI 默认给紧凑构图
- **每个重要场景至少 3 个版本**：全景（默认）、远景（交代环境）、近景/特写（关键剧情）
- 多视角用"近景/远景/俯视"这类专业词，不用"放大/截取"（会破坏透视）
- 物品提示词可简化；但角色会站上去互动（如孤船甲板）→ 按场景标准做

### 5. 群演批量

- 先定身份：家丁=朴素普通（对抗 AI 的"好看"默认审美）；宾客=体面贵气
- 两种策略：单角色生成 + 视频阶段复制（有特写）；群像批量生成（纯背景）
- 群像提示词结构：**风格统一 + 个体差异 + 身份特征**
- 视频阶段必须加：`其余家丁参考@形象，面部不要一样`

## 第二讲 · 分镜（怎么让观众看）

### 1. 剧本解读：可拍摄信息清单

- **场景三要素**：地点（Where）/ 时间（When）/ 内外景（Interior/Exterior），缺一个 AI 就可能拍错
- **人物关系图谱**：对立/同盟、从属/支配、情感纽带 → 落到"谁在哪、朝向谁、什么表情"
- **翻译原则**：状态描述、台词、叙事总结都不可拍，必须转成画面元素

### 2. 景别与镜头

| 景别 | 功能 | 信息量 |
|---|---|---|
| 远景 | 交代时空、氛围 | 环境最大、人物最小 |
| 全景 | 交代位置关系、动作全貌 | 人与环境并重 |
| 中景 | 对话、互动、肢体 | 人物为主（多人戏默认） |
| 近景 | 表情、情绪 | 表情为主 |
| 特写 | 关键细节、情绪高潮 | 极度聚焦 |

- 景别决定**信息量**与**心理距离**（远景旁观、近景共情、特写压迫）
- **一个镜头只承担一个主要叙事任务**
- 递进逻辑：全景/远景交代环境 → 中景交代关系 → 近景/特写交代情绪
- 运镜六种（推/拉/摇/移/跟/升降）：**必须有叙事动机**；单镜头运镜 ≤3 秒
- 角度即权力：俯视=人物弱、仰视=人物强、平视=中立；角度与景别独立组合
- 硬约束：**单场景 ≤15 秒、≤6 个镜头**；有台词压到 4–5 个

### 3. 位置与动作：以镜头为参照系

- ❌"南司站在杨青对面" ✅"南司位于画面左侧，面朝镜头右前方；杨青位于画面右侧"
- 理由：AI 没有自我中心空间推理，每多一步推理就多一份出错概率
- **方位全程一致**：A 在左就一直在左，切镜头不能乱
- 表情逐五官拆：眉毛/眼睛/嘴角/头部/躯干/手臂/手部（"得意"→"嘴角歪斜上扬、眼睛半眯斜视左下、下巴微抬"）
- 复杂情绪拆成矛盾信号：愤怒（眉紧锁、眼圆睁）+ 无力（身体佝偻、手臂垂下）
- 三层构图：前景（遮挡/视角来源，注明虚化）→ 中景（主体）→ 远景（环境）
- 过肩镜头四要素：越过谁的哪个肩 + 拍谁 + 景别 + 角度

### 4. 台词与反应镜头

- 长台词必须拆 2–3 段，段间插**反应镜头**（拍听的人）
- 交替规律：说 → 听 → 说 → 听，最后用无声反应收束
- 反应镜头必须承载情绪，废镜头等于浪费 15 秒；不给同一人连续两个反应
- 超限精简优先级：**合并反应镜头 > 画外音替代 > 跨场景拆分**
- 拆分点：一句话说完或一个动作完成之后；跨场景后第一镜要重建空间关系

### 5. 多参生成 vs 分镜生成

| 判断 | 用多参 | 用分镜 |
|---|---|---|
| 特征 | 无空间参照系、核心是能量/光/气息、时间边界模糊 | 有明确位置关系、需精确控制动作/台词/表情 |
| 例 | 神魂流光涌入、怨气迸发、气息暴涨 | 对话、对峙、击碎巨石 |

- 混合策略：叙事用分镜，意象用多参，过渡段先用分镜建空间锚点
- 有特效≠多参："一掌击碎巨石"动作主体明确，仍用分镜

### 6. 原画分层

先做场景底图 → 再放人物 → 调比例位置 → 输出全景/中景多版本，作为视频生成的视觉锚点。

## 第三讲 · 生成与修复（怎么出片）

### 1. 生成前：资产与 @ 引用

- **上传=入库，@=出库调用**，两者缺一不可；未 @ 的资产 AI 不会用
- 顺序铁律：**先选模型 → 再传资产 → 最后配参数**（换模型会导致资产引用失效）
- 景别决定 @ 谁：全景 @ 场景；中景 @ 场景+人物；近景 @ 人物
- **画外音不 @**：有台词≠在画面里。角色只在声音层面存在时，@ 会把人生拽进画面 → 穿帮
- 同角色首次出现必 @；有台词时建议再 @ 一次强化一致性

### 2. 提示词清理

删除两类无效内容：
- **黑屏/转场占位**（不是实际画面，会浪费一个镜头）
- **"X 秒"预设**（是人工参考值，不是给 AI 的指令，会干扰时长判断）

### 3. 时长公式（关键新增）

```
视频总时长 = 台词字数 ÷ 语速 + 镜头数 × 1 秒
语速：有情绪/极端情绪 4 字/秒；平缓/叙述/嘲讽 5 字/秒
```

示例：30 字平缓 = 6 秒，4 镜 = 4 秒，总 10 秒。
台词时长是**下限**，画面时长是**增量**；估算后再按生成效果微调。

### 4. 穿帮诊断表

| 症状 | 根因 | 处方 |
|---|---|---|
| 手部动作与设定矛盾（被反绑却撑地） | 模型逐词响应，动作词优先于状态词 | 删致错描述 + 显式补"始终被反绑" |
| 场景与资产不符 | 未 @ 场景资产或 @ 错 | 重新 @ 场景，写"严格按照场景生成" |
| 人物一致性丢失（蜡像感/双人/站位错） | 每帧重新画人，无角色记忆 | @ 人物 + "注意保持人物一致性，严格按原画站位" |
| 平台审核拦截 | 用词撞敏感词库 | 同音字/近义词替换，不改原意 |

### 5. 迭代与止损

- 三策略按序试：**删除致错描述 → 补充全局约束 → 强调"严格按照"并再 @ 资产**
- 若强调后仍不对，说明模型理解有偏差 → 换思路或拆片段
- **片段拆分**：一条视频只有部分可用时，只重生成问题片段（3 秒级别），可用片段交剪辑拼接
- 秒数越短，可用率越高——这也是时长要精确计算的原因

- 本文件管**流程**：资产普查 → 风格 → 角色/场景 → 分镜 → 生成 → 诊断

# AI 视频导演台 · Agent

一个导演型 AI Agent：从故事灵感到分镜、角色、场景、提示词、审稿的全链路。核心是 `ai-director` v34 技能。

## 它和普通"视频提示词工具"的区别

它不做选择题，做判断：

- 用「这场必须用侧光」而不是「建议您可以考虑侧光」
- 每个决定都有叙事、情绪或角色的依据
- 会主动指出情绪弧线平、转折点弱、景别没有叙事理由、运镜炫技
- 对故事没有贡献的镜头，直接砍

## 两种用法

**1. 只装技能（推荐先这样）**

把 `skill/` 复制到 `C:\Users\Administrator\.agents\skills\ai-director`，DSH 会自动出现在技能目录里，说「用 ai-director 把这个故事做成分镜」即可。

**2. 装成独立 Agent（preset）**

```powershell
dsh plugin --profile desktop add "file:<本仓库路径>/plugin"
```

在 `dsh.profile.bundles` 加 `"dsh-agent-ai-video"`，改 `plugin/cordis.patch.yml` 里的绝对路径，重启后在 Agent 列表选 `ai-video`。

## 工作链路

```
故事 → 剧本 → 角色设计 → 场景设计 → 分镜头 → 提示词 → 六部门会诊审稿
```

出词必须过五条铁律：

1. 教小孩画画：细节写死，不写"缓缓/高级/电影感"
2. 指令式 > 描述式：用"必须遵循""不得重新诠释"
3. 反面约束 + 正面指令配对
4. 叙事思维：前中远三层 + 五感 + 微表情
5. 量化禁模糊：表情写肌肉角度，动作写发力路径与用时

审稿：总导演 / 表演 / 镜内执行 / 摄影 / 提示词导演 / 场记，6×N 逐镜覆盖。

## 硬规则

- 只出提示词，不生成图片/视频
- 成品 ≤5000 有效字符，超了主动压缩并说明删了什么
- 提示词统一中文
- 未授权不出词（先确认题材、时长、画幅、风格、交付形态）

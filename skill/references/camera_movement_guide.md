# 运镜与景别选择指南

来源整理：个人知识库 02-运镜方式库.md + 07-镜头语言模板库.md + AI导演台导演知识
整合时间：2026-07-07

---

## 核心原则

**先定情绪，再选镜头**。每个镜头都要为情绪和故事服务，不要为了炫技而炫技。

---

## 一、景别选择速查表

| 景别 | 叙事功能 | 什么时候用 | 什么时候别用 |
|------|---------|-----------|------------|
| 大特写 | 极致情绪放大 | 最关键的情绪转折点（眼泪、瞳孔、握拳） | 滥用会失去冲击力 |
| 特写 | 情绪/细节 | 需要看清面部表情变化、手部动作 | 连续多镜特写会让观众迷失空间 |
| 近景 | 对话/意图 | 人物说话、表情变化、两人互动 | 需要展示环境关系时 |
| 中景 | 日常对话/动作 | 最通用的景别，兼顾表情和环境 | 需要极致亲密或极致疏离时 |
| 全景 | 环境/关系 | 交代场景、展示人物与环境关系、群像 | 需要看清表情细节时 |
| 远景 | 宏大/孤独 | 展现地理规模、人物渺小、史诗感 | 需要人物细节时 |
| 大远景 | 终局/收束 | 结尾拉远、人物消失、天地苍茫 | 叙事中段少用 |

## 二、运镜选择速查表

| 运镜 | 叙事含义 | 典型场景 |
|------|---------|---------|
| 缓慢推入 | 聚焦、紧张递增 | 发现线索、情绪积累、关键对话 |
| 快速推入 | 震惊、突发 | 突然意识到什么、打击性信息 |
| 缓慢拉远 | 揭示环境、孤立感 | 结尾、人物孤独、展现全貌 |
| 快速拉远 | 错愕、反转 | 发现真相、局势突变 |
| 固定镜头 | 客观、凝视、仪式感 | 对话、等待、沉思、首尾呼应 |
| 跟拍 | 临场感、紧迫 | 奔跑、行走、追逐 |
| 环绕旋转 | 英雄登场、亲密、眩晕 | 主角出场、拥抱、胜利时刻 |
| 低角度仰视 | 高大、力量、权威 | 英雄、威胁、压迫 |
| 高角度俯视 | 渺小、无助、上帝视角 | 困境、群像、战略视角 |
| 手持晃动 | 真实感、纪实、混乱 | 打斗、逃亡、紧张时刻 |
| 侧面平推 | 平行观察、跟随 | 两人并排、行走、对话 |

## 三、场景→运镜匹配指南

### 1. 逃亡/追逐场景
- 景别：全景（交代环境）→中景（跟上人物）→近景（看清恐惧表情）
- 运镜：快速跟拍+手持晃动+低角度仰拍（逃跑者显得渺小/追兵显得高大）
- 节奏：快切，每镜2-3秒
- 参考：刘邦逃亡S01-S04

### 2. 对话/问答场景
- 景别：近景为主，偶尔切中景/特写
- 运镜：固定镜头（正反打）+缓慢推入（情绪加重时）
- 节奏：中等，每镜3-5秒
- 参考：刘邦逃亡S06（刘邦问樊哙）

### 3. 英雄登场/亮相
- 景别：低角度仰视全景→中景→近景特写
- 运镜：环绕旋转+缓慢推入+终极技拉升
- 节奏：慢→快→慢
- 参考：主角首次出场

### 4. 战斗/打斗场景
- 景别：全景（对峙）→中景（交锋）→特写（关键一击）→全景（结果）
- 运镜：贴身跟随+格挡震动+剑光划过+旋转攻击+子弹时间
- 节奏：快慢交替，蓄力用慢，出击用快
- 参考：古风打斗

### 5. 悲伤/离别场景
- 景别：特写（眼泪/手部）→中景（侧脸）→全景拉远（孤独背影）
- 运镜：固定镜头+极其缓慢推近+快速拉远（结尾）
- 节奏：慢速，长镜头停留
- 参考：刘邦逃亡S07-S08

### 6. 震惊/转折场景
- 景别：大特写（瞳孔放大）→快速推入（整个脸）→定格→快速变焦群镜头（周围人反应）
- 运镜：快速推入+突然静止+后退疏远
- 节奏：先静后动，定格1秒制造冲击

### 7. 温馨/日常场景
- 景别：中景为主，特写穿插
- 运镜：固定镜头+缓慢推入+手持微晃（呼吸感）
- 节奏：舒缓，每镜4-6秒
- 参考：普拉提品牌短片

### 8. 史诗/宏大场景
- 景别：大远景→远景→全景（逐级推进）
- 运镜：上帝视角俯冲+缓慢拉远+FPV穿越
- 节奏：慢速，每镜5-8秒
- 参考：大禹治水开场

### 9. 忠诚/守护场景
- 景别：近景（表情坚定）→中景（守护姿态）
- 运镜：固定镜头+缓慢拉远（展现两人关系）
- 节奏：中速偏慢
- 参考：刘邦逃亡S07（樊哙忠诚）

### 10. 首尾呼应场景
- 开场：固定镜头+缓慢推入（建立氛围）
- 结尾：缓慢拉远→大远景→定格→淡出
- 首尾用相同的声音/画面元素呼应
- 参考：刘邦逃亡S01虫鸣→S08虫鸣

## 四、情绪→镜头组合公式

| 情绪 | 镜头组合 | 节奏 |
|------|---------|------|
| 浪漫/温馨 | 缓慢推入+柔焦+微距缓推 | 慢，3-5秒/镜 |
| 紧张/恐惧 | 快速推入+手持晃动+倾斜构图 | 快，1-2秒/镜 |
| 悲伤/离别 | 特写固定+缓慢拉远+孤独广角 | 慢速长镜头 |
| 愤怒/爆发 | 快速变焦+跳切+低角度仰拍 | 要快，0.5-1秒切换 |
| 英雄/胜利 | 环绕旋转+终极技拉升+慢动作 | 中速转急速 |
| 孤独/绝望 | 高角度俯视+后退疏远+群像拉远 | 慢速，人物偏小 |
| 坚定/决心 | 固定镜头+缓慢推入+正面中景 | 中速，稳定 |

## 五、焦段与光圈速查

### 焦段
| 焦段 | 适合场景 | 视觉特征 |
|------|---------|---------|
| 14-24mm | 建筑、大场面、科幻 | 空间拉伸感、夸张透视 |
| 35mm | 街头、生活、环境人像 | 自然人文感、接近人眼 |
| 50mm | 日常、平实观察 | 标准人眼视角 |
| 85mm | 肖像、人物特写 | 奶油般虚化、人物突出 |
| 100mm微距 | 极致细节 | 纹理清晰、极近特写 |

### 光圈
| 光圈 | 效果 | 适合场景 |
|------|------|---------|
| 大光圈f/1.4-f/2.8 | 背景虚化、主体突出 | 人物肖像、特写 |
| 中光圈f/4-f/5.6 | 主体清晰+环境可辨 | 环境人像、生活场景 |
| 小光圈f/8-f/16 | 全景清晰、细节丰富 | 大场景、建筑风景 |

## 六、运镜禁忌

1. **不要无目的运镜**：每个运镜都要有叙事理由，"好看"不是理由
2. **不要全程动态**：激烈运动后必须接静态长镜头，动静结合才有呼吸
3. **不要滥用特写**：大特写只用在最关键的情绪点，用多了没冲击力
4. **不要连续同景别**：相邻两镜景别必须变化，否则像卡顿
5. **不要运镜和情绪矛盾**：悲伤场景不用快速运镜，紧张场景不用固定长镜头（除非刻意反差）
